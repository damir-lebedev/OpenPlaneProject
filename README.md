## OpenPlaneProject — открытый инженерный проект по разработке экспериментального радиоуправляемого самолёта и систем его управления.

Цель проекта — создать доступную платформу для изучения:

- авиамоделирования;
- аэродинамики;
- 3D-печати;
- электроники;
- микроконтроллеров;
- систем управления;
- автономных летательных аппаратов.

## Идея проекта

Я хочу документировать весь процесс разработки: от первых неудачных прототипов до работающей летающей платформы.

Проект развивается публично. Здесь будут публиковаться:

- исходный код прошивки;
- 3D-модели деталей;
- схемы электроники;
- результаты испытаний;
- ошибки и способы их исправления;
- технические заметки и расчёты.

Главная цель — сделать инженерную разработку понятнее и доступнее для других энтузиастов.

## Текущий прототип

На данный момент разрабатывается самолёт со следующими характеристиками:

- размах крыла: 1200 мм;
- хорда крыла: 250 мм;
- профиль крыла: NACA 4412;
- материал конструкции: PETG;
- управление: ESP32;
- сервоприводы: MG90S;
- двигатель: D2212 1000KV;
- регулятор: 40A ESC;
- пропеллер: 10×5;
- питание: LiPo 3S;
- элероны: отдельный сервопривод на каждую поверхность.

Конструкция находится в стадии разработки и испытаний.

## Статус проекта

🚧 Work in progress

Первый прототип уже прошёл испытания и выявил несколько проблем:

- недостаточная прочность крепления двигателя;
- недостаточная прочность крыла;
- необходимость усиления конструкции карбоновыми элементами;
- необходимость улучшения управления и настройки сервоприводов.

Следующая цель — довести конструкцию до стабильного и безопасного полёта.

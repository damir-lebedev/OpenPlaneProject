# RC Joystick — пульт FS-i6 как USB-джойстик

Отдельная прошивка для ESP32-S3: плата читает каналы пульта и отдаёт их
компьютеру как обычный USB-джойстик — для тренировки в симуляторе
(PicaSim, Aerofly RC, RealFlight...) со своим пультом.

С прошивкой полётника **не связана**: свой `platformio.ini`, свой код, ни
одного общего файла. На плату шьётся либо она, либо полётная — каждая
заливка целиком заменяет предыдущую.

```
pio run -d tools/rc-joystick -t upload     # из корня репозитория: плата = джойстик
pio run -t upload                          # вернуть прошивку полётника
```

## Подключение

| Что | Куда |
|---|---|
| iBUS SERVO приёмника FS-iA6B (как на стенде полётника) | GPIO17, питание приёмника 5V / GND |
| или PPM тренерского разъёма пульта | GPIO14 через резистор 1 кОм, земля общая; уровень сначала проверить (≤ 3.3 В) |
| компьютер | разъём **"USB"** платы — это джойстик |
| лог | разъём **"COM"**, 115200 — откуда сигнал, значения каналов |

В тренерском разъёме FS-i6 — **PPM** (длительность импульса = положение
стика), а не UART, поэтому USB-UART переходник его не прочитает. Если
сигнал есть и там и там — берётся iBUS.

## Что видит компьютер

"HID-compliant game controller", драйверы не нужны (Windows: Панель
управления → "Игровые устройства").

- Оси: CH1–CH8 → X, Y, Z, Rx, Ry, Rz, ползунок 1, ползунок 2; 0..1000 =
  1000..2000 мкс, полное разрешение пульта.
- Кнопки 1–6: CH5–CH10 выше 1750 мкс — тумблеры можно назначить в
  симуляторе кнопками.
- Нет сигнала — стики в центре, газ внизу.

Назначение осей (какой стик — крен, какой — газ) делается в настройках
симулятора.

## ⚡ За 1 Минуту

**Что здесь?**
- Микроконтроллер ESP32-C3, который управляет самолётом
- Приёмник iBUS получает команды с пульта
- Код преобразует команды в управляющие сигналы
- Сервоприводы и мотор получают PWM сигналы

**Сигнал идёт так:**
```
Пульт (2.4 GHz) → Приёмник (UART GPIO3) → ESP32-C3 (обработка)
                                              ↓
                          Сервоприводы (GPIO4-6) + ESC (GPIO7)
```

---

## 🔌 Как Подключить

### Приёмник iBUS

```
Приёмник ESP32-C3
─────────────────
GND     → GND
VCC     → 3V3 (или 5V если приёмник 5V)
RX/DATA → GPIO3 (UART1 RX)
```

### Сервоприводы

```
Сервопривод       ESP32-C3
───────────────────────────
GND       → GND
VCC       → 5V (не 3V3! сервам нужно 5V)
Signal    → GPIO (см. ниже)

Назначение:
Left Aileron  → GPIO4
Right Aileron → GPIO5
Elevator      → GPIO6
```

### ESC (Motor Controller)

```
ESC           ESP32-C3
──────────────────────
GND   → GND
Power → LiPo батарея (НЕ подключать к ESP32!)
Signal → GPIO7
```

## 🎮 Как Использовать

### Включить Систему

```
1. Подключить LiPo батарею
2. Включить пульт управления
3. Должны загореться LED на ESP32 и приёмнике
4. Через ~1 сек система готова
```

### Вооружить Систему (ARM)

```
1. Убедиться, что Failsafe НЕ активирован
   (смотрите Serial Monitor: "Failsafe: NO")

2. Удержать газ (CH3) на МИНИМУМЕ (самое низкое положение)
   в течение 2 СЕКУНД

3. Система вооружится: "Armed: YES"

4. Теперь можно поднимать газ и летать!
```

### Отключить Систему

```
Мотор выключить: опустить газ на минимум
Систему разоружить: просто оставить газ на минимуме
Выключить питание: отсоединить батарею
```

## 📊 Каналы Пульта (10 каналов)

```
Основные (всегда используются):

CH1 — Aileron     → Крены (Roll)      — LEFT STICK HORIZONTAL
CH2 — Elevator    → Тангаж (Pitch)    — LEFT STICK VERTICAL
CH3 — Throttle    → Мотор (0–100%)    — THROTTLE SLIDER
CH5 — Flaps       → Закрылки (3 поз.) — 3-POS SWITCH

Дополнительные:

CH4 — Rudder      → НЕ ИСПОЛЬЗУЕТСЯ
CH6 — Boost       → Ускорение (5 сек) — 2-POS SWITCH
CH7–CH10          → Зарезервированы для GPS/IMU/Autopilot
```

**Диапазон:** 1000–2000 микросекунд (µs)
- 1000 µs = минимум (0%)
- 1500 µs = центр (50%)
- 2000 µs = максимум (100%)

## 🔍 Как Отладить

### Шаг 1: Откройте Serial Monitor

```
VS Code → Extensions → PlatformIO
или
Arduino IDE → Tools → Serial Monitor

Baudrate: 115200
```

### Шаг 2: Должны Видеть Вывод Каждые 500ms

```
===== FLIGHT CONTROLLER STATE =====
Time: 1234567 ms
Failsafe: NO ← Важно! должно быть NO
Armed: NO

RC CHANNELS:
CH1 (Aileron)   1500 µs
CH2 (Elevator)  1500 µs
CH3 (Throttle)  1000 µs
... и т.д.

SERVO OUTPUTS:
Left Aileron   1500 µs
Right Aileron  1500 µs
Elevator       1500 µs
Motor (ESC)    1000 µs (OFF)
===================================
```

### Шаг 3: Проверить Каналы

Двигайте stick'ами на пульте:
```
✓ Значения меняются в Serial Monitor
✓ Failsafe остаётся NO
✓ Каналы идут от 1000 до 2000 µs
```

Если что-то не так → см. `DEBUGGING_GUIDE.md`

## 🛩️ Типичный Полёт

```
1. ПОДГОТОВКА
   □ Проверить соединения GPIO4-7
   □ Батарея пульта полная?
   □ LiPo батарея полная?
   □ Пропеллер свободен?

2. ЗАПУСК
   □ Включить пульт
   □ Подключить батарею
   □ Увидеть "Failsafe: NO" в Serial Monitor

3. ВООРУЖЕНИЕ
   □ Газ на минимум
   □ Подождать 2 сек
   □ Система должна сказать "Armed: YES"

4. ПОЛЁТ
   □ Медленно поднять газ
   □ Проверить, что мотор вращается
   □ Управлять stick'ами
   □ Сервоприводы должны реагировать

5. ПРИЗЕМЛЕНИЕ
   □ Опустить газ
   □ Когда приземлился → газ на минимум
   □ Система разоружится (Armed: NO)
   □ Отключить батарею
```

## 🆘 Частые Проблемы

### Приёмник Не Видит Пульт

```
Признак: Failsafe: YES при включённом пульте
Решение: Проверить GPIO3 соединение приёмника
```

### Система Не ARM-ится

```
Признак: Удерживаю газ внизу, но Armed: NO
Решение: Проверить, что Failsafe: NO
         Удерживать газ ровно 2 сек без перерыва
```

### Сервоприводы Не Двигаются

```
Признак: Servo PWM = 1500 µs, но servo не шевелится
Решение: Проверить GPIO4-6 соединения
         Проверить питание servo (нужно 5V!)
```

### Мотор Не Вращается

```
Признак: Газ поднят, но Motor PWM = 1000 µs (OFF)
Решение: Проверить, что система ARMED (Armed: YES)
         Проверить GPIO7 соединение ESC
         Проверить батарею (может быть разряжена)
```

**Подробно смотрите `DEBUGGING_GUIDE.md`**

## 📖 Как Читать Код

### main.cpp

```cpp
// ← ОЧЕНЬ ХОРОШИЕ КОММЕНТАРИИ! Читать обязательно!

void loop()
{
    // Вызываем главный контроллер каждый цикл
    flightController.update();  // ← ВСЯ МАГИЯ ЗДЕСЬ!
    
    // Отладочная информация
    debugLogger.update();
    
    // Небольшая пауза
    delay(2);
}
```

### Как Работает Полёт?

```
flightController.update()
├─ Получить данные: receiver.update()
├─ Проверить failsafe: if (isSignalLost()) → выход!
├─ Вооружение: arming.update()
├─ Управление поверхностями: mixer.calculate()
├─ Управление мотором: throttle.update()
└─ Отправить PWM: outputs.write()

← ВСЯ ЛОГИКА УПРАВЛЕНИЯ ЗДЕСЬ! Потом цикл повторяется.
```

### Где Добавить Новый Функционал?

```
Новый датчик (IMU)?     → Новый класс + в FlightController
Автопилот?              → Новый класс + использует mixer
GPS навигация?          → Новый класс + координирует полёт
Телеметрия?             → Новый класс + отправляет данные
Второй мотор?           → Модифицировать ThrottleManager
```

- **Батарея:** LiPo 3S (11.1V номинал)

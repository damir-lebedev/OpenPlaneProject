## Что переведено

README, [airframe/README.md](../../airframe/README.md), лицензия, все руководства из
`docs/` (пилота, автопилота, плата, архитектура, тесты, чёрный ящик, дорожная карта,
руководство разработчика) и весь справочник `docs/reference/`. Исходники прошивки,
идентификаторы, имена файлов, команды и тексты, которые прошивка печатает по-русски,
не переводятся.

## Правила

- **Лицензия.** Юридически обязателен только английский текст — [LICENSE](../../LICENSE).
  Переводы лицензии (`<язык>/LICENSE.md`) неофициальны и нужны для удобства чтения.
- **Расхождения.** Если перевод и русский оригинал расходятся, прав оригинал.
- **Структура зеркальная.** Абзац в абзац, строка таблицы в строку, блок кода в блок
  кода, те же заголовки. Ссылки и якоря в переводах ведут на переведённые страницы.
- **Единицы и термины.** Единицы пишутся латиницей (Hz, ms, µs, m/s, MB), термины берутся
  из [глоссария](GLOSSARY.md).
- **Не «open source».** Лицензия OpenPlane — это MIT плюс обязательное указание автора,
  запрет военного применения и умышленного вреда; формально она не входит в список OSI,
  поэтому переводы не называют её «open source» без оговорки.

## Как обновлять

Переводы делаются вручную и держатся в актуальном состоянии вместе с оригиналом: изменили
русский документ — обновите соответствующий кусок во всех языках, не меняя число абзацев,
таблиц, блоков кода и заголовков (по нему расставляются якоря). Языковая панель в начале
каждого README и ссылки между переведёнными страницами не правятся руками — их
ставит сборочный скрипт.

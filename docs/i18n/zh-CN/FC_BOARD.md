# 飞控板：接口分组

> 🌐 本页是[俄语原文](../../FC_BOARD.md)的译文。译文与原文如有出入，以原文为准。固件的控制台信息以俄语输出，因此文中照原样引用。 本译文由 AI 完成，未经母语者审校。如发现错误，请联系 [Damir Lebedev](https://github.com/damir-lebedev)，或在[问题追踪页](https://github.com/damir-lebedev/OpenPlaneProject/issues)中提出。

这是一块 ESP32-S3 DevKitC-1（N16R8）的载板：DevKit 插在两排母座排针上，周围是成组的 JST-XH 接口。本文回答三个问题：把哪些接口焊成一组，电容放在哪里，以及什么插到哪里。引脚与 `include/config/Config.h`（`BOARD_ESP32_S3` 部分）一致。

这块板子是按**单面板**设计的：GPIO 的选择使得每一组接口的引脚沿着 DevKit 的排针连续排列，信号走线呈扇形散开，互不交叉。我没有在 CAD 里检查过布线。如果某处走不通，就在元件面上用导线飞一根跳线：这样一块板上有一到三根跳线是正常的。

**所有接口都是 JST-XH，1–5 针。** 导线不直接焊在板子上：舵机、ESC、接收机和各模块的导线上要压接配套的插头壳。XH 带有防呆键，所以不可能插反。每个针脚能通过约 3 A 的电流。

## 1. 布局示意图

俯视图，从元件面看。DevKit 的 USB 接口在下边缘。

```
                    顶部：ESP 天线，其下不铺铜
+----------------------------------------------------------------------+
| 沿整个板边的 GND 环                                                  |
|  (470 µF)              3V3 --------------------+    +- C5 IMU        |
|  A1 AIL-L               ^  （DevKit 端部后方） |    +- C4 BARO       |
|  A2 AIL-R               |                      |    +- C3 I2C-B      |
|  A3 ELE          +------+-------------+        |    +- C2 I2C-A      |
|  A4 ESC <-BEC    | J1-1,2: 3V3        |        +--->+- C1 OLED       |
|  A5 AUX1  <------| J1-4..11   J3-4..7 |-------------^  I2C 轨        |
|  A6 AUX2         |                    |                              |
|  A7 RC           |      DevKit        | J3-8..10 --> D1 GPS          |
|  A8 RUD          |     ESP32-S3       |              D2 BUZ   [Q1]   |
|  (470 µF)        |                    |                              |
|  B1 BAT   <------| J1-12,13           | J3-17,18 --> D3 AUX3         |
|  B2 TELEM <------| J1-15,16           |              D4 LIGHT [Q2]   |
|                  | J1-21: 5V          |                  ^           |
|                  +----[USB]--[COM]----+                  | 逻辑 5V   |
|    [二极管 1N5822] --> 逻辑 5V --- 底边，USB 下方 -------+           |
+----------------------------------------------------------------------+
```

四个区域：

| 区域 | 位置 | 内容 | 供电 |
|---|---|---|---|
| **A** 舵机 | 左边缘，正对 J1-4…11 | 8 个 XH-3：舵面、ESC、AUX、接收机 | 舵机 5V（脏电源） |
| **B** 电池、遥测 | 左下，正对 J1-12…16 | 电池和电流传感器、数传电台 | 逻辑 5V |
| **C** 3V3 | 右上，正对 J3-4…7 | OLED、I2C 轨上的传感器、I2C 接口 | 3V3 |
| **D** 逻辑 5V | 右下，正对 J3-8…18 | GPS、蜂鸣器、AUX3、灯光 | 逻辑 5V |

左边是功率部分（舵机、ESC、电池），右边是传感器和通信。舵机的电流留在左边，不会流经传感器旁边。

## 2. DevKit 排针：每个针脚接到哪里

针脚顺序与 ESP32-S3-DevKitC-1（2 × 22）相同。动手画板之前，请对照你那块板子的丝印，并量一下两排之间的距离。编号从天线一端数向 USB 一端。

|---|---|---|---|---|---|---|
| 1 | 3V3 | 3V3 经顶部 → C 区 | | 1 | GND | — |
| 2 | 3V3 | （同上） | | 2 | 43 | —（“COM”控制台） |
| 3 | RST | — | | 3 | 44 | —（“COM”控制台） |
| 4 | 4 | A1 AIL-L | | 4 | 1 | C1 OLED SDA |
| 5 | 5 | A2 AIL-R | | 5 | 2 | C1 OLED SCL |
| 6 | 6 | A3 ELE | | 6 | 42 | I2C 轨：SCL |
| 7 | 7 | A4 ESC | | 7 | 41 | I2C 轨：SDA |
| 8 | 15 | A5 AUX1 | | 8 | 40 | D1 GPS：TX |
| 9 | 16 | A6 AUX2 | | 9 | 39 | D1 GPS：RX |
| 10 | 17 | A7 RC（iBUS） | | 10 | 38 | D2 蜂鸣器（经 Q1） |
| 11 | 18 | A8 RUD | | 11 | 37 | — PSRAM |
| 12 | 8 | B1 VBAT（ADC） | | 12 | 36 | — PSRAM |
| 13 | 3 | B1 CURR（ADC） | | 13 | 35 | — PSRAM |
| 14 | 46 | — strapping | | 14 | 0 | — BOOT 按键 |
| 15 | 9 | B2 TELEM：TX | | 15 | 45 | — strapping |
| 16 | 10 | B2 TELEM：RX | | 16 | 48 | — RGB LED |

## 3. 想挤进单层板要遵守的规则

1. **插件在上面，贴片在下面。** DevKit 的母座、XH 接口、电解电容和二极管放在元件面。0805、0603 和 SOT-23 直接焊在铜面上。用热转印法制板时，铜箔图形要镜像打印。
2. **每个接口里：信号靠近 DevKit，电源在外侧，GND 在边缘。** 所以所有接口都是**1 号针离 DevKit 最近**。这样信号走线就不会穿过电源线。例外是 I2C 轨（第 5 条）。
3. **GND 是沿整个边缘的铺铜**（一圈环）。接口最外侧的针脚直接接到它上面。
4. **从 DevKit 的一侧到另一侧只经过两根线。** 3V3 从 J1-1/2 向上走，绕过 DevKit 的上端，再向右——在 DevKit 板子的边缘之外，不从天线下面走。逻辑 5V 从 J1-21 出发，从 DevKit 下面向下，再沿下边缘向右，从 USB 接口下方走过（那里只有走线，插头悬在更高的位置）。
5. **I2C 轨。** 四根平行走线，间距 2.54 mm，从 DevKit 向外延伸：**3V3 · GND · SCL · SDA**。这是 GY 系列模块的引脚顺序（VCC GND SCL SDA）。母座和接口横跨在轨道上，像火车车厢：每根走线从各自的针脚穿过。轨道从 J3-6/7 开始，钻到 OLED 下面，再沿右排向上延伸。如果高度不够，就在 DevKit 上端向左折过去，转弯时各线的顺序保持不变。
6. **不要让走线从 DevKit 的针脚之间穿过**：2.54 的间距对热转印来说太窄。在 DevKit 本体下面可以走线，那里离它的电路板有 11 mm 的空间。
7. **插件就是免费的跳线。** 走线可以轻松地从二极管的壳体下面（引脚间距 12.5–15 mm）和电解电容的两脚之间（5 mm）穿过。
8. **0805 放在接口的针脚之间。** XH 的间距是 2.5 mm——0805 电容可以直接在铜面这一侧焊在相邻的 +5V 和 GND 针脚之间。
9. **走线宽度：** 舵机 5V 和舵机 GND——2 mm 起，逻辑 5V——1 mm 起，信号线——0.4–0.5 mm。
10. **丝印标注：** 接口编号（A1、B2……）、名称，以及 1 号针处的箭头。

## 4. 接口分组

### A 组——舵机：8 个 XH-3，左边缘，纵向排成一列，正对 J1-4…11

每个接口里的针脚：
**1——信号**（靠近 DevKit）· **2——舵机 +5V** · **3——GND**（靠近边缘）。这是舵机导线的顺序：橙、红、棕。

| 接口 | 标注 | 接什么 | GPIO（针脚） |
|---|---|---|---|
| A1 | AIL-L | 左副翼 | 4（J1-4） |
| A2 | AIL-R | 右副翼 | 5（J1-5） |
| A3 | ELE | 升降舵 | 6（J1-6） |
| A4 | ESC | 电调：油门信号；**红线上——BEC 5V 输入** | 7（J1-7） |
| A5 | AUX1 | 载荷投放舵机 | 15（J1-8） |
| A6 | AUX2 | 襟翼（两个舵机通过 Y 形线）或任意舵机 | 16（J1-9） |
| A7 | RC | FS-iA6B 接收机，iBUS SERVO 端口（接收机由这里供电） | 17（J1-10） |
| A8 | RUD | 方向舵 + 车轮 | 18（J1-11） |

这一组里还要焊的东西：

- **舵机 +5V 母线**——中间一列针脚，走线 2 mm 起。**GND**——外侧一列，同时也是 GND 环的一部分。
- **330 Ω（0603）** 串在每根信号线上，靠近接口。如果 5 V 误接到信号针脚上（舵机损坏、压接不良），ESP 的引脚也能保住。
- **10 kΩ（0603）** 从 A4 ESC 的信号线接到 GND：ESP 重启期间，不会有干扰信号窜到电调上。
- **100 nF（0805）** 接在每个接口的 2 号和 3 号针脚之间。
- **A4 ESC** 另外还有 10 µF + 100 pF（0805）：整块板子的电源输入——低频、高频和超高频滤波。
- **A7 RC** 另外还有 10 µF（0805）：接收机对电压跌落很敏感。
- **2 × 470 µF 16 V** 接在舵机母线上，这一列的每一端各放一个（A1 上方和 A8 下方）：正极接母线，负极接环。在这一列的中间，负极走不到环上，而对电解电容来说，3 cm 宽的走线并没有影响。

一个 ESC 接口能通过约 3 A 的电流。对于 4–6 个 MG90S 舵机，这足够了。如果舵机更多、功率更大，就在 A4 旁边再加一个单独的 BEC 供电接口。

### B 组——电池和遥测，左下，位于舵机的下方

**B1 BAT——XH-5**（板上唯一的 XH-5：带有 12–17 V 的线缆插不进其他任何接口）

| 针脚 | 内容 | 板上去向 |
|---|---|---|
| 1 | **VBAT**——用细导线接电池正极（平衡头最外侧的“+”，或取自电池接头，不要经过 ESC） | 56 kΩ / 10 kΩ 分压器 → GPIO8（J1-12） |
| 2 | 空——把电池电压与其他针脚隔开的空隙 | — |
| 3 | **CURR**——电流传感器的输出 | 10 kΩ / 15 kΩ 分压器 → GPIO3（J1-13） |
| 4 | 逻辑 +5V——给电流传感器供电 | 逻辑 5V 母线 |
| 5 | GND | 环 |

- **VBAT 分压器**：上臂 56 kΩ，下臂 10 kΩ，下臂并联 100 nF。3S（12.6 V）→ 1.91 V，4S（16.8 V）→ 2.55 V——距 ADC 上限（约 3.1 V）还有余量。不需要单独的地线：地线通过 ESC 是共用的，5 号针可以不压接。
- **CURR 分压器**：上臂 10 kΩ，下臂 15 kΩ，下臂并联 100 nF。5 V 的霍尔传感器（ACS758 之类）最大输出 5 V → 引脚上为 3.0 V。如果传感器输出是 3.3 V，上臂电阻用 0 Ω，下臂电阻不焊。
- 分压器紧靠接口放置，地线从它的 5 号针取——这样接到 ESP 的就只有一根走线。
- 暂时没有电流传感器？3–4 号针干脆不压接。

**B2 TELEM——XH-4**：遥测数传电台或 iBUS-SENS。

| 针脚 | 内容 | GPIO（针脚） |
|---|---|---|
| 1 | TX → 接电台的 RX | 9（J1-15） |
| 2 | RX ← 来自电台的 TX | 10（J1-16） |
| 3 | 逻辑 +5V | — |
| 4 | GND | — |

- 3 号和 4 号针之间接 10 µF + 100 nF。对于 1 W 的电台，再加一个 470 µF 的电解电容。
- 固件目前还不支持 TELEM：三个 UART 都已被占用（控制台、iBUS、GPS）。要启用它，需要把控制台改到内置 USB 上。这需要改固件；接口本身现在就可以布线。

### C 组——3V3：屏幕和传感器，右上

这个区域里的一切都挂在 **I2C 轨**上（第 3 节第 5 条）：四根走线 **3V3 · GND · SCL · SDA** 从 DevKit 向外延伸。SCL 来自 GPIO42（J3-6），SDA 来自 GPIO41（J3-7）。3V3 经顶部从 J1-1/2 过来。OLED 位于轨道的最下面，它上面依次是 C2–C5。

**C1 OLED——XH-4。** 电源取自轨道，数据取自它自己的总线（GPIO1/2），从内侧引过来。

| 针脚 | 内容 | 来自 |
|---|---|---|
| 1 | SDA | GPIO1（J3-4） |
| 2 | SCL | GPIO2（J3-5） |
| 3 | 3V3 | 轨道 |
| 4 | GND | 轨道 |

这正好是 OLED 模块引脚顺序（GND VCC SCL SDA）的倒序，所以线缆不需要扭转。

**C2 I2C-A 和 C3 I2C-B——XH-4**，完全一样：

| 针脚 | 内容 |
|---|---|
| 1 | 3V3 |
| 2 | GND |
| 3 | SCL |
| 4 | SDA |

- **C2**——罗盘：装在支杆上的 GY-273（直连线缆，顺序与模块相同），或者 GPS 模块里的罗盘。对于 GPS，只压接 GND、SCL 和 SDA：罗盘的电源通过 GPS 的线缆获得。
- **C3**——备用：空速传感器（MS4525DO）、测距仪等。

**C4 BARO——用于 BMP581 模块的 1×4 母座**：1——VCC，2——GND，3——SCL，4——SDA。

- 在模块上自己焊上跳线 **CSB→VCC** 和 **SDO→GND**（地址 0x46；0x47 留给皮托管）。没有 CSB→VCC，芯片会进入 SPI 模式；SDO 悬空，地址就不确定。模块的其余引脚悬空。
- 只接轨道上的 3V3：很多 BMP581 模块没有自己的稳压器。
- 不同的模块引脚顺序不同——请对照你自己的模块。如果顺序对不上，就把模块用线缆接到 C3，母座不装。
- 上面盖一小块开孔海绵（防气流和光线）。

**C5 IMU——用于 GY-521 的 1×8 母座**：

| 针脚 | 模块引脚 | 接到 |
|---|---|---|
| 1 | VCC | 3V3 轨 |
| 2 | GND | GND 轨 |
| 3 | SCL | SCL 轨 |
| 4 | SDA | SDA 轨 |
| 5、6 | XDA、XCL | 不接 |
| 7 | AD0 | 接到轨道外侧的 GND 铺铜（地址 0x68） |
| 8 | INT | 不接 |

IMU 在板上怎么旋转并不重要：安装方式由 `o` 校准确定（PILOT_GUIDE，“IMU 的安装”）。

单独的 MPU-6500 模块（10 个引脚：VCC GND SCL SDA EDA ECL AD0 INT NCS FSYNC）插不进这个母座——引脚顺序不同。它用线缆接到 C3（VCC、GND、SCL、SDA），模块上焊跳线 **NCS→VCC**（否则芯片会进入 SPI 模式）、**AD0→GND**（地址 0x68）和 **FSYNC→GND**。

这一组的电容：轨道上 C1 处（3V3 从这里开始）的 **10 µF + 100 nF**，C2–C5 处 1 号和 2 号针之间的 **100 nF**。I2C 的上拉电阻已经在模块上了，板子上不要再装。

### D 组——逻辑 5V：GPS、蜂鸣器、灯光，右下

逻辑 5V 母线从下方进入（从 DevKit 下面沿下边缘过来），再沿右边缘向上，依次穿过这一组所有接口的“+5V”针脚。

**D1 GPS——XH-4。** 它紧挨着轨道的下方，这样 GPS 的插座和它的罗盘插座（C2）就离得很近。

| 针脚 | 内容 | GPIO（针脚） |
|---|---|---|
| 1 | TX → 接 GPS 的 RX | 40（J3-8） |
| 2 | RX ← 来自 GPS 的 TX | 39（J3-9） |
| 3 | 逻辑 +5V | — |
| 4 | GND | — |

3 号和 4 号针之间接 10 µF + 100 nF。

**D2 BUZ——XH-2**：5 V 有源蜂鸣器，用来在草丛里找到飞机，以及提示电池和 ARM 状态。

| 针脚 | 内容 |
|---|---|
| 1 | 蜂鸣器的“−” → 开关管 Q1 |
| 2 | 逻辑 +5V → 蜂鸣器的“+” |

**D3 AUX3——XH-3**：1——GPIO47（J3-17）的信号，经 330 Ω；2——逻辑 +5V；3——GND；另外在 2 和 3 之间接 100 nF。适合接按钮、LED 灯带的数据线、相机触发。**不要在这里接舵机**：这是逻辑 5V，舵机的电流会经过二极管，把 ESP 的电源拉得上下波动。

**D4 LIGHT——XH-2**：负载最大约 0.5–1 A 的开关——航行灯、大灯、投放用的电磁铁。

| 针脚 | 内容 |
|---|---|
| 1 | 负载的“−” → 开关管 Q2 |
| 2 | 逻辑 +5V → 负载的“+” |

**开关管 Q1 和 Q2**——同一个 SOT-23 焊盘。BC817 和 Si2302 的引脚作用对应：

| SOT-23 引脚 | BC817 | Si2302 | 接到 |
|---|---|---|---|
| 1 | 基极 | 栅极 | ← 1 kΩ ← GPIO（Q1 用 38，Q2 用 21）；1 号脚到 GND 接 10 kΩ |
| 2 | 发射极 | 源极 | GND（本区地线——J3-21/22） |
| 3 | 集电极 | 漏极 | 接口的 1 号针（D2 / D4） |

- **Q1（蜂鸣器）**：两种都可以。
- **Q2（灯光）**：用 **Si2302**——BC817 在几百毫安下会发热。
- 10 kΩ 让开关管在 ESP 启动期间保持关断：蜂鸣器不乱叫，灯不乱闪。
- 如果负载是线圈（电磁铁、电磁式蜂鸣器），在接口两端并联一个 SS14 或 1N4148 二极管，阴极接 +5V。在 1 号和 2 号针之间给它留出位置。

## 5. 电源和所有电容

```
 ESC (BEC 5V/5A) ──► A4 ──► 舵机 5V 母线 ──┬──► A1…A8 （舵机、接收机）
                                           │    列两端各 2×470 µF
                                           │
                                           └──► 二极管 1N5822 ──► 逻辑 5V ──┬──► J1-21 (5V DevKit)
                                                                            ├──► B1, B2 （电流传感器、电台）
                                                                            └──► D1…D4 （GPS、蜂鸣器、AUX3、灯光）
 DevKit：自带 3V3 稳压器 ──► J1-1/2 ──► 绕过顶部 ──► C 轨（OLED、传感器、I2C 接口）
```

- **输入只有一个——A4 ESC。** 不需要单独的电源接口。
- **1N5822 肖特基二极管**（3 A，插件；贴片替代品是 SS34）——需要购买。它起三个作用：
  - USB 和 BEC 互不顶撞：电池接上时可以一直插着 USB；
  - 舵机把母线拉低时，逻辑部分的电解电容不会向舵机反向放电，ESP 也不会重启；
  - 插件封装的外壳可以充当跨过 J1-22 附近拐角处 GND 走线的跳线。

  阳极接舵机母线的下端，阴极接 J1-21。不要用 1N5819（1 A）：ESP、电台、GPS 和灯光的电流都要从这个二极管通过。
- 只靠 USB 无法给舵机供电，二极管会把它们隔断。这是有意为之。在桌上用 USB 供电时，GPS、电台和蜂鸣器只有在 DevKit 的 5V 引脚从 USB 取电时才能工作。有些仿制板在那里自带一个二极管，这样它们就不工作了——这是正常的。
- 3.3 V 只来自 DevKit 的稳压器，而且只供 C 区使用。

**所有电容放在一张表里**（陶瓷电容——0805，电解电容——16 V）：

| 位置 | 内容 | 作用 |
|---|---|---|
| 舵机母线，A1 上方和 A8 下方 | 470 µF + 470 µF | 抑制所有舵机同时动作时的电压跌落 |
| A4 ESC，+ 与 GND 之间 | 10 µF + 100 nF + 100 pF | 电源输入：低频、高频和超高频 |
| A1–A3、A5–A8 | 每个 100 nF | 舵机电机的干扰——就在源头处滤除 |
| A7 RC | + 10 µF | 接收机 |
| 逻辑 5V，J1-21 处 | 470 µF + 10 µF + 100 nF | BEC 电压跌落时托住 ESP |
| 3V3 轨，C1 处 | 10 µF + 100 nF | 传感器供电 |
| C2–C5 | 每个 100 nF | |
| B1：VBAT 和 CURR 的 ADC 输入 | 每个 100 nF，与下臂电阻并联 | ADC 滤波 |
| B1：电流传感器的 +5V | 4 号和 5 号针之间 100 nF | |
| B2 TELEM | 10 µF + 100 nF（1 W 电台——再加 470 µF） | 发射机的电流尖峰 |
| D1 GPS | 10 µF + 100 nF | |

0805 封装的 10 µF 陶瓷电容在 5 V 下会损失多达一半的容量——这一点已经考虑在内，而且旁边反正有电解电容。

测试点：**5VS**（舵机母线）、**5VL**（逻辑 5V）、**3V3**、**GND**。用万用表测量时很方便。

## 8. 哪些 GPIO 不要动

0、45、46——启动模式取决于它们；19/20——USB；26–37——N16R8 模块的闪存和 PSRAM；43/44——“COM”接口（控制台）；48——RGB LED。按这个方案，剩下可用的只有 GPIO11–14（在台架上——SPI）。

## 9. 第一次上电之前

1. 不装 DevKit，也不接电池，先用万用表测通断：舵机 +5V ↔ GND、逻辑 5V ↔ GND、3V3 ↔ GND——任何地方都不应该短路。
2. 接上 BEC（通过 A4），此时还没有插 DevKit。5VS 上应该是 5.0–5.2 V，5VL 上比它低 0.3–0.5 V（二极管上的压降）。
3. 插上 DevKit，只接 USB。5VS 上是 0 V：二极管不让 USB 的电进入舵机。
4. 全部连起来。控制台里的 `s` 会显示传感器是否有响应，以及 I2C 上有多少错误。

## 10. 与上一版方案相比有哪些变化

- **引脚为适应单层板重新调整过了**（已写入 `Config.h`）：
  - 传感器 I2C 8/9 → **41/42**；
  - GPS 15/16 → **39/40**；
  - AUX1/AUX2 41/42 → **15/16**；
  - VBAT 3 → **8**，电流传感器 10 → **3**；
  - 遥测 39/40 → **9/10**；
  - 在 GPIO21 上新增了 **LIGHT** 输出。

  在台架上请调换两根线：SDA 8 → 41，SCL 9 → 42。其余引脚是备用的，台架上没有接。
- **通过 ESC 使用唯一的 BEC**：单独的 PWR 接口取消了。
- **板上的传感器走 I2C**（与台架一致）。SPI 母座取消了，GPIO11–14 空闲。ICM-42688 也支持 I2C，但固件需要在 `SensorSelection.h` 中为它增加 I2C 方案。
- **GPS-MAG 取消了**：GPS 的罗盘插到 C2 上。
- **VBAT 和电流传感器合并**到同一个 XH-5（B1）里。

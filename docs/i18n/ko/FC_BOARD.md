# 비행 컨트롤러 보드: 커넥터 블록

> 🌐 이 문서는 [러시아어 원문](../../FC_BOARD.md)을 번역한 것입니다. 번역과 원문이 다를 경우 원문이 우선합니다. 펌웨어는 콘솔 메시지를 러시아어로 출력하므로 그대로 인용했습니다. 이 번역은 AI가 작성했으며 원어민의 검수를 거치지 않았습니다. 오류를 발견하면 [Damir Lebedev](https://github.com/damir-lebedev)에게 알려 주시거나 [이슈](https://github.com/damir-lebedev/OpenPlaneProject/issues)로 남겨 주세요.

ESP32-S3 DevKitC-1(N16R8)용 캐리어 보드입니다. DevKit를 암 핀 헤더 두 줄에 꽂고, 그 주위에 JST-XH 커넥터 블록을 둡니다. 이 문서는 세 가지 질문에 답합니다. 어떤 커넥터를 블록으로 묶을지, 커패시터를 어디에 놓을지, 무엇을 어디에 꽂을지입니다. 핀은 `include/config/Config.h`(`BOARD_ESP32_S3` 블록)와 일치합니다.

보드는 **단면**으로 만들 수 있게 설계했습니다. 각 블록의 핀이 DevKit 헤더를 따라 연속으로 놓이고 신호 배선이 서로 교차하지 않고 부채꼴로 퍼지도록 GPIO를 골랐습니다. 배선은 CAD에서 확인하지 않았습니다. 어딘가에서 안 맞으면 부품면 쪽에 전선 점퍼를 넣으세요. 이런 보드에서는 한두 개에서 세 개 정도는 정상입니다.

**모든 커넥터는 JST-XH이며 1–5핀입니다.** 전선은 보드에 납땜하지 않습니다. 서보, ESC, 수신기, 모듈의 전선에 짝이 되는 하우징을 압착합니다. XH에는 방향 키가 있어서 거꾸로 꽂을 수 없습니다. 핀 하나는 약 3 A를 견딥니다.

---

## 1. 배치도

위에서 본 모습이며, 부품면에서 본 것입니다. DevKit의 USB 커넥터는 아래쪽 가장자리에 있습니다.

```
                    위: ESP 안테나, 그 아래에는 구리 없음
+----------------------------------------------------------------------+
| 가장자리 전체를 두르는 GND 링                                        |
|  (470 µF)              3V3 --------------------+    +- C5 IMU        |
|  A1 AIL-L               ^  (DevKit 끝 뒤쪽)    |    +- C4 BARO       |
|  A2 AIL-R               |                      |    +- C3 I2C-B      |
|  A3 ELE          +------+-------------+        |    +- C2 I2C-A      |
|  A4 ESC <-BEC    | J1-1,2: 3V3        |        +--->+- C1 OLED       |
|  A5 AUX1  <------| J1-4..11   J3-4..7 |-------------^  I2C 레일      |
|  A6 AUX2         |                    |                              |
|  A7 RC           |      DevKit        | J3-8..10 --> D1 GPS          |
|  A8 RUD          |     ESP32-S3       |              D2 BUZ   [Q1]   |
|  (470 µF)        |                    |                              |
|  B1 BAT   <------| J1-12,13           | J3-17,18 --> D3 AUX3         |
|  B2 TELEM <------| J1-15,16           |              D4 LIGHT [Q2]   |
|                  | J1-21: 5V          |                  ^           |
|                  +----[USB]--[COM]----+                  | 로직 5V   |
|    [다이오드 1N5822] --> 로직 5V --- 아래쪽, USB 아래 ---+           |
+----------------------------------------------------------------------+
```

네 개의 영역이 있습니다.

| 영역 | 위치 | 내용 | 전원 |
|---|---|---|---|
| **A** 서보 | 왼쪽 가장자리, J1-4…11 맞은편 | XH-3 8개: 조종면, ESC, AUX, 수신기 | 서보 5V(노이즈가 많음) |
| **B** 배터리, 텔레메트리 | 왼쪽 아래, J1-12…16 맞은편 | 배터리와 전류 센서, 무선 모뎀 | 로직 5V |
| **C** 3V3 | 오른쪽 위, J3-4…7 맞은편 | OLED, I2C 레일의 센서, I2C 커넥터 | 3V3 |
| **D** 로직 5V | 오른쪽 아래, J3-8…18 맞은편 | GPS, 부저, AUX3, 라이트 | 로직 5V |

왼쪽은 전력부(서보, ESC, 배터리)이고, 오른쪽은 센서와 통신입니다. 서보 전류는 왼쪽에만 머물고 센서 옆을 지나가지 않습니다.

## 2. DevKit 헤더: 어느 핀이 어디로

핀 순서는 ESP32-S3-DevKitC-1(2 × 22)과 같습니다. 설계하기 전에 본인 보드의 실크 인쇄와 대조하고 두 줄 사이의 간격을 재 보세요. 번호는 안테나 쪽에서 USB 쪽으로 매깁니다.

| J1(왼쪽 줄) | GPIO | 연결 대상 | | J3(오른쪽 줄) | GPIO | 연결 대상 |
|---|---|---|---|---|---|---|
| 1 | 3V3 | 위쪽을 거쳐 3V3 → 영역 C | | 1 | GND | — |
| 2 | 3V3 | (위와 같음) | | 2 | 43 | —("COM" 콘솔) |
| 3 | RST | — | | 3 | 44 | —("COM" 콘솔) |
| 4 | 4 | A1 AIL-L | | 4 | 1 | C1 OLED SDA |
| 5 | 5 | A2 AIL-R | | 5 | 2 | C1 OLED SCL |
| 6 | 6 | A3 ELE | | 6 | 42 | I2C 레일: SCL |
| 7 | 7 | A4 ESC | | 7 | 41 | I2C 레일: SDA |
| 8 | 15 | A5 AUX1 | | 8 | 40 | D1 GPS: TX |
| 9 | 16 | A6 AUX2 | | 9 | 39 | D1 GPS: RX |
| 10 | 17 | A7 RC(iBUS) | | 10 | 38 | D2 부저(Q1 경유) |
| 11 | 18 | A8 RUD | | 11 | 37 | — PSRAM |
| 12 | 8 | B1 VBAT(ADC) | | 12 | 36 | — PSRAM |
| 13 | 3 | B1 CURR(ADC) | | 13 | 35 | — PSRAM |
| 14 | 46 | — 스트래핑 | | 14 | 0 | — BOOT 버튼 |
| 15 | 9 | B2 TELEM: TX | | 15 | 45 | — 스트래핑 |
| 16 | 10 | B2 TELEM: RX | | 16 | 48 | — RGB LED |
| 17 | 11 | 비어 있음 | | 17 | 47 | D3 AUX3 |
| 18 | 12 | 비어 있음 | | 18 | 21 | D4 LIGHT(Q2 경유) |
| 19 | 13 | 비어 있음 | | 19 | 20 | — USB |
| 20 | 14 | 비어 있음 | | 20 | 19 | — USB |
| 21 | 5V | 로직 5V 입력(다이오드 뒤) | | 21 | GND | 영역 D의 접지 |
| 22 | GND | 영역 B의 접지 | | 22 | GND | 영역 D의 접지 |

테스트 벤치에서는 펌웨어가 비어 있는 GPIO11–14를 SPI(ICM-42688)에 쓰지만, 이 보드에는 SPI를 빼 놓지 않았습니다.

## 3. 한 층에 담기 위한 규칙

1. **리드 부품은 위, SMD는 아래.** DevKit 소켓, XH, 전해 커패시터, 다이오드는 부품면에 놓습니다. 0805, 0603, SOT-23은 구리에 직접 납땜합니다. 토너 전사(다리미 방식)에서는 구리 패턴을 좌우 반전해서 인쇄합니다.
2. **각 커넥터에서 신호는 DevKit에 더 가깝게, 전원은 더 멀리, GND는 가장자리 쪽에 둡니다.** 그래서 모든 커넥터에서 **1번 핀이 DevKit에서 가장 가까운 핀**입니다. 그러면 신호 배선이 전원을 가로지르지 않습니다. 예외는 I2C 레일입니다(5번 항목).
3. **GND는 둘레 전체를 두르는 면(링)으로 만듭니다.** 커넥터의 가장 바깥쪽 핀은 곧바로 거기에 연결됩니다.
4. **DevKit의 한쪽에서 반대쪽으로 넘어가는 선은 두 개뿐입니다.** 3V3은 J1-1/2에서 위로 올라가 DevKit의 위쪽 끝을 지나 오른쪽으로 갑니다. DevKit 기판의 가장자리 밖으로 지나가며, 안테나 아래로는 지나가지 않습니다. 로직 5V는 J1-21에서 DevKit 아래로 내려가 아래쪽 가장자리를 따라 오른쪽으로 가며, USB 커넥터 아래를 지납니다(거기에는 배선만 있고 플러그는 더 위에 떠 있습니다).
5. **I2C 레일.** DevKit에서 바깥쪽으로 뻗는, 간격 2.54 mm의 평행한 배선 네 가닥으로, 순서는 **3V3 · GND · SCL · SDA**입니다. GY 모듈의 핀 순서(VCC GND SCL SDA)입니다. 소켓과 커넥터는 기차 객차처럼 레일을 가로질러 놓이고, 각 배선은 자기 핀을 지나갑니다. 레일은 J3-6/7에서 시작해 OLED 아래로 들어가 오른쪽 줄을 따라 위로 올라갑니다. 높이에 맞지 않으면 DevKit의 위쪽 끝 위에서 왼쪽으로 꺾으세요. 꺾어도 선의 순서는 그대로 유지됩니다.
6. **DevKit의 핀 사이로는 배선을 지나가게 하지 마세요.** 2.54 간격은 토너 전사에 너무 좁습니다. DevKit 바로 아래는 괜찮습니다. 거기에는 DevKit 기판까지 11 mm의 여유가 있습니다.
7. **리드 부품은 공짜 점퍼입니다.** 다이오드 몸체 아래(리드 간격 12.5–15 mm)와 전해 커패시터의 다리 사이(5 mm)로 배선이 넉넉히 지나갑니다.
8. **커넥터 핀 사이에 0805.** XH의 간격이 2.5 mm이므로, 0805 커패시터를 이웃한 +5V와 GND 핀 사이에 구리면 쪽에서 곧바로 납땜할 수 있습니다.
9. **배선 폭:** 서보 5V와 서보 GND는 2 mm 이상, 로직 5V는 1 mm 이상, 신호는 0.4–0.5 mm.
10. **실크 인쇄 표기:** 커넥터 번호(A1, B2…), 이름, 그리고 1번 핀 옆의 화살표.

## 4. 커넥터 블록

### 블록 A: 서보. XH-3 8개, 왼쪽 가장자리, J1-4…11 맞은편에 한 줄로

각 커넥터의 핀:
**1: 신호**(DevKit에 가까운 쪽) · **2: 서보 +5V** · **3: GND**(가장자리 쪽).
서보 전선의 순서입니다. 주황, 빨강, 갈색입니다.

| 커넥터 | 표기 | 꽂는 것 | GPIO(핀) |
|---|---|---|---|
| A1 | AIL-L | 왼쪽 에일러론 | 4(J1-4) |
| A2 | AIL-R | 오른쪽 에일러론 | 5(J1-5) |
| A3 | ELE | 승강타 | 6(J1-6) |
| A4 | ESC | 변속기: 스로틀 신호. **빨간 선은 BEC 5V 입력** | 7(J1-7) |
| A5 | AUX1 | 화물 투하 서보 | 15(J1-8) |
| A6 | AUX2 | 플랩(서보 2개를 Y 케이블로) 또는 아무 서보 | 16(J1-9) |
| A7 | RC | 수신기 FS-iA6B의 iBUS SERVO 포트(수신기는 여기서 전원을 받음) | 17(J1-10) |
| A8 | RUD | 방향타 + 바퀴 | 18(J1-11) |

블록에 납땜하는 것은 더 있습니다.

- **서보 +5V 버스**: 핀의 가운데 열이며, 배선은 2 mm 이상입니다. **GND**: 바깥쪽 열이며, GND 링의 일부이기도 합니다.
- 각 신호선의 중간, 커넥터 가까이에 **330 Ω(0603)** 저항을 직렬로 넣습니다. 신호 핀에 5 V가 걸려도(서보 불량, 압착 불량 등) ESP의 핀은 살아남습니다.
- A4 ESC 신호에서 GND로 **10 kΩ(0603)** 저항을 넣습니다. ESP가 재부팅하는 동안 변속기로 잡신호가 들어가지 않습니다.
- 각 커넥터의 2번과 3번 핀 사이에 **100 nF(0805)** 커패시터를 넣습니다.
- **A4 ESC**에는 10 µF + 100 pF(0805)를 추가합니다. 보드 전체의 전원 입력이며, 저주파·고주파·초고주파를 걸러 줍니다.
- **A7 RC**에는 10 µF(0805)를 추가합니다. 수신기는 전압 강하에 민감합니다.
- **2 × 470 µF 16 V**를 서보 버스에, 열의 양 끝에 하나씩(A1 위와 A8 아래) 넣습니다. 플러스는 버스에, 마이너스는 링에 연결합니다. 열의 중간에서는 마이너스를 링까지 보낼 수 없지만, 전해 커패시터는 굵은 배선이 3 cm 길어져도 상관없습니다.

ESC용 소켓 하나는 약 3 A를 견딥니다. MG90S 서보 4–6개에는 이것으로 충분합니다. 서보가 더 늘고 더 강력해진다면 A4 옆에 BEC에서 오는 별도의 전원 소켓을 추가하세요.

### 블록 B: 배터리와 텔레메트리, 왼쪽 아래 서보 아래

**B1 BAT: XH-5**(보드에서 유일한 XH-5입니다. 12–17 V 케이블은 다른 어떤 커넥터에도 들어가지 않습니다)

| 핀 | 내용 | 보드에서 연결되는 곳 |
|---|---|---|
| 1 | **VBAT**: 가는 선으로 배터리 플러스(밸런스 단자의 가장 바깥쪽 "+" 또는 배터리 커넥터에서. ESC를 거치지 않음) | 56 kΩ / 10 kΩ 분압기 → GPIO8(J1-12) |
| 2 | 비어 있음: 배터리 전압과 나머지 핀 사이의 간격 | — |
| 3 | **CURR**: 전류 센서의 출력 | 10 kΩ / 15 kΩ 분압기 → GPIO3(J1-13) |
| 4 | 로직 +5V: 전류 센서의 전원 | 로직 5V 버스 |
| 5 | GND | 링 |

- **VBAT 분압기:** 위쪽 56 kΩ, 아래쪽 10 kΩ, 아래쪽 저항에 100 nF를 병렬로 붙입니다. 3S(12.6 V) → 1.91 V, 4S(16.8 V) → 2.55 V로, ADC 한계(약 3.1 V)까지 여유가 있습니다. 접지선을 따로 둘 필요는 없습니다. 접지는 ESC를 통해 공통이므로 5번 핀은 압착하지 않아도 됩니다.
- **CURR 분압기:** 위쪽 10 kΩ, 아래쪽 15 kΩ, 아래쪽 저항에 100 nF를 병렬로 붙입니다. 5 V 홀 센서(ACS758 등)는 최대 5 V를 내보내므로 핀에서는 3.0 V가 됩니다. 센서 출력이 3.3 V라면 위쪽 저항은 0 Ω으로 하고 아래쪽은 납땜하지 않습니다.
- 분압기는 커넥터 바로 옆에 두고, 접지는 그 커넥터의 5번 핀에서 가져오세요. 그러면 ESP로 가는 배선이 하나만 남습니다.
- 전류 센서가 아직 없다면 3–4번 핀은 압착하지 마세요.

**B2 TELEM: XH-4.** 텔레메트리 무선 모뎀 또는 iBUS-SENS용입니다.

| 핀 | 내용 | GPIO(핀) |
|---|---|---|
| 1 | TX → 모뎀의 RX로 | 9(J1-15) |
| 2 | RX ← 모뎀의 TX에서 | 10(J1-16) |
| 3 | 로직 +5V | — |
| 4 | GND | — |

- 3번과 4번 핀 사이에 10 µF + 100 nF를 넣습니다. 1 W 모뎀에는 470 µF 전해 커패시터를 추가하세요.
- 펌웨어는 아직 TELEM을 지원하지 않습니다. UART 세 개가 모두 사용 중이기 때문입니다(콘솔, iBUS, GPS). 켜려면 콘솔을 내장 USB로 옮겨야 합니다. 이것은 펌웨어를 고쳐야 하는 일이며, 커넥터의 배선은 지금 해 둘 수 있습니다.

### 블록 C: 3V3 화면과 센서, 오른쪽 위

이 영역의 모든 것은 **I2C 레일**에 올라갑니다(3절 5번 항목). DevKit에서 바깥쪽으로 뻗는 네 가닥의 배선 **3V3 · GND · SCL · SDA**입니다. SCL은 GPIO42(J3-6)에서, SDA는 GPIO41(J3-7)에서 옵니다. 3V3은 J1-1/2에서 위쪽을 돌아 옵니다. OLED가 레일의 가장 아래에 놓이고, 그 위에 순서대로 C2–C5가 놓입니다.

**C1 OLED: XH-4.** 전원은 레일에서, 데이터는 전용 버스(GPIO1/2)에서 가져오며, 안쪽에서 접근합니다.

| 핀 | 내용 | 출처 |
|---|---|---|
| 1 | SDA | GPIO1(J3-4) |
| 2 | SCL | GPIO2(J3-5) |
| 3 | 3V3 | 레일 |
| 4 | GND | 레일 |

OLED 모듈의 핀 순서(GND VCC SCL SDA)를 거꾸로 한 것이어서, 케이블이 꼬이지 않고 지나갑니다.

**C2 I2C-A와 C3 I2C-B: XH-4**, 둘은 동일합니다.

| 핀 | 내용 |
|---|---|
| 1 | 3V3 |
| 2 | GND |
| 3 | SCL |
| 4 | SDA |

- **C2**: 나침반용입니다. 마스트 위의 GY-273(일자 케이블, 순서는 모듈과 같음) 또는 GPS 모듈의 나침반을 연결합니다. GPS에서는 GND, SCL, SDA만 압착합니다. 나침반은 GPS 케이블로 전원을 받습니다.
- **C3**: 예비용입니다. 대기속도 센서(MS4525DO), 거리계 등을 연결합니다.

**C4 BARO: BMP581 모듈용 1×4 소켓.** 1: VCC, 2: GND, 3: SCL, 4: SDA.

- 모듈 쪽에 와이어 점퍼 **CSB→VCC**와 **SDO→GND**를 납땜하세요(주소 0x46, 0x47은 피토관용으로 비워 둡니다). CSB→VCC가 없으면 칩이 SPI 모드로 빠지고, SDO가 떠 있으면 주소가 흔들립니다. 모듈의 나머지 핀은 공중에 띄워 둡니다.
- 전원은 레일의 3V3만 쓰세요. 많은 BMP581 모듈에 자체 레귤레이터가 없습니다.
- 모듈은 제품마다 핀 순서가 다르니 본인 모듈을 확인하세요. 맞지 않으면 모듈을 케이블로 C3에 연결하고 소켓은 달지 않습니다.
- 위에는 기공이 열린 스펀지 조각을 얹습니다(공기 흐름과 빛을 막기 위해서입니다).

**C5 IMU: GY-521용 1×8 소켓**

| 핀 | 모듈 단자 | 연결처 |
|---|---|---|
| 1 | VCC | 3V3 레일 |
| 2 | GND | GND 레일 |
| 3 | SCL | SCL 레일 |
| 4 | SDA | SDA 레일 |
| 5, 6 | XDA, XCL | 연결하지 않음 |
| 7 | AD0 | 레일 바깥쪽 GND 면에(주소 0x68) |
| 8 | INT | 연결하지 않음 |

IMU를 보드 위에서 어떤 방향으로 놓았는지는 중요하지 않습니다. 설치 방향은 `o` 캘리브레이션이 정합니다(PILOT_GUIDE의 "IMU 설치").

별도 MPU-6500 모듈(10핀: VCC GND SCL SDA EDA ECL AD0 INT NCS FSYNC)은 핀 순서가 달라 이 소켓에 맞지 않습니다. 케이블로 C3에 연결하고(VCC, GND, SCL, SDA), 모듈에 점퍼 **NCS→VCC**(그렇지 않으면 칩이 SPI 모드로 빠집니다), **AD0→GND**(주소 0x68), **FSYNC→GND**를 납땜합니다.

블록의 커패시터: 레일의 C1 자리(3V3이 시작되는 곳)에 **10 µF + 100 nF**, C2–C5에는 1번과 2번 핀 사이에 **100 nF**를 넣습니다. I2C 풀업 저항은 이미 모듈에 달려 있으니 보드에는 달지 마세요.

### 블록 D: 로직 5V의 GPS, 부저, 라이트, 오른쪽 아래

로직 5V 버스는 아래에서(DevKit 아래를 지나 아래쪽 가장자리를 따라) 들어와, 오른쪽 가장자리를 따라 블록의 모든 커넥터의 "+5V" 핀을 지나며 올라갑니다.

**D1 GPS: XH-4.** 레일 바로 아래에 놓아서 GPS 소켓과 그 나침반(C2) 소켓이 가까이 있게 합니다.

| 핀 | 내용 | GPIO(핀) |
|---|---|---|
| 1 | TX → GPS의 RX로 | 40(J3-8) |
| 2 | RX ← GPS의 TX에서 | 39(J3-9) |
| 3 | 로직 +5V | — |
| 4 | GND | — |

3번과 4번 핀 사이에 10 µF + 100 nF를 넣습니다.

**D2 BUZ: XH-2.** 풀숲에서 비행기를 찾거나 배터리와 ARM 상태를 알려 주는 5 V 능동 부저입니다.

| 핀 | 내용 |
|---|---|
| 1 | 부저의 "−" → 스위치 Q1 |
| 2 | 로직 +5V → 부저의 "+" |

**D3 AUX3: XH-3.** 1: GPIO47(J3-17)의 신호를 330 Ω을 거쳐, 2: 로직 +5V, 3: GND이고, 2번과 3번 사이에 100 nF를 넣습니다. 버튼, LED 스트립의 데이터, 카메라 트리거에 쓸 수 있습니다. **여기에 서보를 달지 마세요.** 로직 5V이므로 서보 전류가 다이오드를 지나 ESP의 전원을 흔들게 됩니다.

**D4 LIGHT: XH-2.** 약 0.5–1 A까지의 부하용 스위치입니다. 항법등, 헤드라이트, 투하용 전자석 등에 씁니다.

| 핀 | 내용 |
|---|---|
| 1 | 부하의 "−" → 스위치 Q2 |
| 2 | 로직 +5V → 부하의 "+" |

**스위치 Q1과 Q2**는 같은 SOT-23 풋프린트입니다. BC817과 Si2302는 다리의 역할이 서로 대응합니다.

| SOT-23 다리 | BC817 | Si2302 | 연결처 |
|---|---|---|---|
| 1 | 베이스 | 게이트 | ← 1 kΩ ← GPIO(Q1은 38, Q2는 21). 다리 1에서 GND로 10 kΩ |
| 2 | 이미터 | 소스 | GND(영역의 접지: J3-21/22) |
| 3 | 컬렉터 | 드레인 | 커넥터의 1번 핀(D2 / D4) |

- **Q1(부저):** 둘 중 아무거나 됩니다.
- **Q2(라이트):** **Si2302**를 쓰세요. BC817은 수백 mA에서 뜨거워집니다.
- 10 kΩ은 ESP가 부팅하는 동안 스위치를 꺼진 상태로 유지합니다. 부저가 울어 대지 않고 라이트가 깜박이지 않습니다.
- 부하가 코일(전자석, 전자식 부저)이라면 SS14 또는 1N4148 다이오드를 커넥터와 병렬로, 캐소드가 +5V 쪽으로 가게 달아 주세요. 1번과 2번 핀 사이에 자리를 남겨 두세요.

## 5. 전원과 모든 커패시터

```
 ESC (BEC 5V/5A) ──► A4 ──► 서보 5V 버스 ──┬──► A1…A8 (서보, 수신기)
                                           │    열의 양 끝에 2×470 µF
                                           │
                                           └──► 다이오드 1N5822 ──► 로직 5V ──┬──► J1-21 (5V DevKit)
                                                                              ├──► B1, B2 (전류 센서, 모뎀)
                                                                              └──► D1…D4 (GPS, 부저, AUX3, 라이트)
 DevKit: 자체 3V3 레귤레이터 ──► J1-1/2 ──► 위쪽을 거쳐 ──► 레일 C(OLED, 센서, I2C 커넥터)
```

- **입력은 하나뿐입니다: A4 ESC.** 별도의 전원 커넥터는 필요 없습니다.
- **1N5822 쇼트키 다이오드**(3 A, 리드형이며 SMD 대체품은 SS34)는 구매해야 합니다. 세 가지 일을 합니다.
  - USB와 BEC가 서로 부딪치지 않습니다. 배터리를 연결한 채로 USB를 꽂아 둘 수 있습니다.
  - 서보가 버스 전압을 끌어내려도 로직 쪽 전해 커패시터가 서보 쪽으로 거꾸로 방전되지 않고, ESP도 재부팅되지 않습니다.
  - 리드형 몸체가 J1-22 옆 모서리에서 GND 배선을 건너는 점퍼 역할을 합니다.

  애노드는 서보 버스의 아래쪽 끝에, 캐소드는 J1-21에 연결합니다. 1N5819(1 A)는 쓰지 마세요. ESP, 모뎀, GPS, 라이트의 전류가 모두 이 다이오드를 지나갑니다.
- USB만으로는 서보에 전원이 들어가지 않습니다. 다이오드가 끊어 줍니다. 의도한 동작입니다. 책상에서 USB로 GPS, 모뎀, 부저가 동작하는 것은 DevKit의 5V 핀이 USB에서 전원을 내보내는 경우뿐입니다. 일부 클론에는 거기에 자체 다이오드가 있어서 그런 경우에는 동작하지 않습니다. 정상입니다.
- 3.3 V는 DevKit의 레귤레이터에서만, 그리고 영역 C에만 공급합니다.

**모든 커패시터를 한 표로 정리했습니다**(세라믹은 0805, 전해는 16 V).

| 위치 | 내용 | 목적 |
|---|---|---|
| 서보 버스, A1 위와 A8 아래 | 470 µF + 470 µF | 서보가 한꺼번에 움직일 때의 전압 강하 |
| A4 ESC, +와 GND 사이 | 10 µF + 100 nF + 100 pF | 전원 입력: 저주파, 고주파, 초고주파 |
| A1–A3, A5–A8 | 각각 100 nF | 서보 모터의 노이즈(발생원에서) |
| A7 RC | + 10 µF | 수신기 |
| 로직 5V, J1-21 | 470 µF + 10 µF + 100 nF | BEC가 처질 때 ESP를 받쳐 줌 |
| 3V3 레일, C1 | 10 µF + 100 nF | 센서 전원 |
| C2–C5 | 각각 100 nF | |
| B1: VBAT와 CURR의 ADC 입력 | 각각 100 nF, 아래쪽 저항과 병렬 | ADC 필터 |
| B1: 전류 센서의 +5V | 4번과 5번 핀 사이에 100 nF | |
| B2 TELEM | 10 µF + 100 nF(1 W 모뎀이면 + 470 µF) | 송신기의 전류 스파이크 |
| D1 GPS | 10 µF + 100 nF | |
| D3 AUX3 | 100 nF | |

0805 크기의 10 µF 세라믹은 5 V에서 용량이 최대 절반까지 줄어듭니다. 이는 감안한 것이고, 어차피 근처에 전해 커패시터도 있습니다.

테스트 포인트: **5VS**(서보 버스), **5VL**(로직 5V), **3V3**, **GND**. 멀티미터로 측정하기 편한 곳입니다.

## 8. 건드리지 말아야 할 GPIO

0, 45, 46: 부팅 모드가 이 핀들에 달려 있습니다. 19/20: USB. 26–37: N16R8 모듈의 플래시와 PSRAM. 43/44: "COM" 커넥터(콘솔). 48: RGB LED. 이 계획에서 남는 것은 GPIO11–14뿐입니다(테스트 벤치에서는 SPI).

## 9. 처음 전원을 켜기 전에

1. DevKit과 배터리 없이 도통을 확인합니다. 서보 +5V ↔ GND, 로직 5V ↔ GND, 3V3 ↔ GND 어디에도 단락이 있어서는 안 됩니다.
2. BEC를 연결합니다(A4 경유). DevKit은 아직 꽂지 않은 상태입니다. 5VS에는 5.0–5.2 V가, 5VL에는 그보다 0.3–0.5 V 낮은 전압(다이오드에서의 강하)이 나와야 합니다.
3. DevKit을 꽂고 USB만 연결합니다. 5VS는 0 V입니다. 다이오드가 USB 전원이 서보로 들어가지 못하게 막습니다.
4. 모두 함께 연결합니다. 콘솔의 `s`가 센서가 응답하는지, I2C에 오류가 몇 건인지 보여 줍니다.

## 10. 이전 계획과 달라진 점

- **핀을 한 층에 맞게 다시 배정했습니다**(`Config.h`에는 이미 반영됨).
  - 센서 I2C: 8/9 → **41/42**
  - GPS: 15/16 → **39/40**
  - AUX1/AUX2: 41/42 → **15/16**
  - VBAT: 3 → **8**, 전류 센서: 10 → **3**
  - 텔레메트리: 39/40 → **9/10**
  - 새 출력 **LIGHT**를 GPIO21에 추가

  테스트 벤치에서는 전선 두 가닥을 옮기세요. SDA 8 → 41, SCL 9 → 42입니다. 나머지 핀은 예비이며 테스트 벤치에는 연결되어 있지 않습니다.
- **BEC는 ESC를 거치는 하나뿐**: 별도의 PWR 커넥터는 없앴습니다.
- **보드의 센서는 I2C에 연결**합니다(테스트 벤치와 같습니다). SPI 소켓은 없앴고 GPIO11–14는 비어 있습니다. ICM-42688은 I2C로도 동작하지만, 펌웨어에 `SensorSelection.h`의 I2C 버전이 필요합니다.
- **GPS-MAG는 없앴습니다**: GPS의 나침반은 C2에 꽂습니다.
- **VBAT와 전류 센서를 합쳐** 하나의 XH-5(B1)로 만들었습니다.

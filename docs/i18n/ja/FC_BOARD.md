# フライトコントローラー基板：コネクターのブロック

> 🌐 このページは[ロシア語の原文](../../FC_BOARD.md)の翻訳です。翻訳と原文に違いがある場合は、原文が優先されます。ファームウェアはコンソールメッセージをロシア語で出力するため、そのまま引用しています。 この翻訳は AI によるもので、ネイティブスピーカーによる確認は行っていません。誤りを見つけたら、[Damir Lebedev](https://github.com/damir-lebedev) までご連絡いただくか、[Issue](https://github.com/damir-lebedev/OpenPlaneProject/issues) でお知らせください。

ESP32-S3 DevKitC-1（N16R8）用のキャリア基板です。DevKit は 2 本のメスのピンソケットに差し込み、その周囲に JST-XH コネクターのブロックを配置します。この文書は、どのコネクターをブロックにまとめるか、コンデンサーをどこに置くか、何をどこにつなぐか、という 3 つの疑問に答えます。ピンは `include/config/Config.h`（`BOARD_ESP32_S3` ブロック）と一致しています。

基板は**片面**で作れるように考えてあります。各ブロックのピンが DevKit のヘッダーに沿って連続し、信号の配線が交差せずに扇状に広がるように GPIO を選んであります。配線は CAD では確認していません。どこかでうまくいかない場合は、部品面側に電線のジャンパーを入れてください。このような基板なら 1〜3 本は普通です。

**コネクターはすべて JST-XH で、1〜5 極です**。配線は基板にはんだ付けしません。サーボ、ESC、受信機、各モジュールの線には、対になるハウジングを圧着します。XH には向きを示すキーがあるので、逆には挿せません。1 つの接点は約 3 A に耐えます。

## 1. 配置図

上から見た図で、部品面から見ています。DevKit の USB コネクターは下の縁にあります。

```
                    上：ESP のアンテナ、その下に銅箔なし
+----------------------------------------------------------------------+
| 縁全体を囲む GND リング                                              |
|  (470 µF)              3V3 --------------------+    +- C5 IMU        |
|  A1 AIL-L               ^  （DevKit の端の裏） |    +- C4 BARO       |
|  A2 AIL-R               |                      |    +- C3 I2C-B      |
|  A3 ELE          +------+-------------+        |    +- C2 I2C-A      |
|  A4 ESC <-BEC    | J1-1,2: 3V3        |        +--->+- C1 OLED       |
|  A5 AUX1  <------| J1-4..11   J3-4..7 |-------------^  I2C レール    |
|  A6 AUX2         |                    |                              |
|  A7 RC           |      DevKit        | J3-8..10 --> D1 GPS          |
|  A8 RUD          |     ESP32-S3       |              D2 BUZ   [Q1]   |
|  (470 µF)        |                    |                              |
|  B1 BAT   <------| J1-12,13           | J3-17,18 --> D3 AUX3         |
|  B2 TELEM <------| J1-15,16           |              D4 LIGHT [Q2]   |
|                  | J1-21: 5V          |                  ^           |
|                  +----[USB]--[COM]----+                  | 論理 5V   |
|    [ダイオード 1N5822] --> 論理 5V --- 下辺、USB の下 ---+           |
+----------------------------------------------------------------------+
```

4 つのエリアがあります。

| エリア | 場所 | 内容 | 電源 |
|---|---|---|---|
| **A** サーボ | 左の縁、J1-4〜11 の向かい | XH-3 が 8 個：舵面、ESC、AUX、受信機 | サーボ用 5V（ノイズが多い） |
| **B** バッテリー、テレメトリー | 左下、J1-12〜16 の向かい | バッテリーと電流のセンサー、無線モデム | ロジック用 5V |
| **C** 3V3 | 右上、J3-4〜7 の向かい | OLED、I2C レール上のセンサー、I2C コネクター | 3V3 |
| **D** ロジック用 5V | 右下、J3-8〜18 の向かい | GPS、ブザー、AUX3、ライト | ロジック用 5V |

左側が電力系（サーボ、ESC、バッテリー）、右側がセンサーと通信です。サーボの電流は左側にとどまり、センサーの脇を通りません。

| 2 | 3V3 | （同上） | | 2 | 43 | —（「COM」コンソール） |
| 3 | RST | — | | 3 | 44 | —（「COM」コンソール） |
| 4 | 4 | A1 AIL-L | | 4 | 1 | C1 OLED SDA |
| 5 | 5 | A2 AIL-R | | 5 | 2 | C1 OLED SCL |
| 6 | 6 | A3 ELE | | 6 | 42 | I2C レール：SCL |

## 3. 1 層に収めるためのルール

1. **リード部品は上、SMD は下。** DevKit のソケット、XH、電解コンデンサー、ダイオードは部品面に置きます。0805、0603、SOT-23 は銅箔に直接はんだ付けします。トナー転写（アイロン法）では、銅箔のパターンを鏡像で印刷します。
2. **各コネクターでは、信号を DevKit に近く、電源を遠く、GND を縁側に置きます**。そのため、すべてのコネクターで**ピン 1 が DevKit に最も近い接点**です。こうすると信号の配線が電源を横切りません。例外は I2C レールです（項目 5）。
3. **GND は外周全体のベタ（リング状）にします**。コネクターの両端の接点は、そのまま GND に落とします。
4. **DevKit の片側から反対側へ渡るのは 2 本の線だけです。** 3V3 は J1-1/2 から上へ出て、DevKit の上端を越え、右へ向かいます。DevKit の基板の縁の外側を通し、アンテナの下は通しません。ロジック用 5V は J1-21 から DevKit の下を通って下へ出て、下の縁に沿って右へ向かい、USB コネクターの下を通ります（そこにあるのは配線だけで、プラグはもっと上に浮いています）。
5. **I2C レール。** DevKit から外へ向かう、間隔 2.54 mm の平行な 4 本の配線で、順に **3V3 · GND · SCL · SDA** です。これは GY モジュールのピン順（VCC GND SCL SDA）です。ソケットやコネクターは、貨車のようにレールを横切る向きで並べ、各配線がそれぞれの接点を通り抜けます。レールは J3-6/7 から始まり、OLED の下に潜り込んで、右の列に沿って上へ向かいます。高さに収まらないときは、DevKit の上端の上で左へ折り曲げてください。曲がっても線の順序は保たれます。
6. **DevKit のピンの間には配線を通さないでください。** 2.54 の間隔は、トナー転写には狭すぎます。DevKit の真下なら配線できます。そこは DevKit の基板まで 11 mm あります。
7. **リード部品は無料のジャンパーです**。ダイオードの本体の下（リード間隔 12.5〜15 mm）や電解コンデンサーの足の間（5 mm）には、配線を楽に通せます。
8. **コネクターの接点の間に 0805。** XH の間隔は 2.5 mm なので、0805 のコンデンサーは、隣り合う +5V と GND の接点の間に、銅箔側から直接はんだ付けできます。
9. **配線幅**：サーボ用 5V とサーボ用 GND は 2 mm 以上、ロジック用 5V は 1 mm 以上、信号は 0.4〜0.5 mm。
10. **シルク印刷の表示**：コネクター番号（A1、B2 ...）、名称、ピン 1 の脇の矢印。

## 4. コネクターのブロック

### ブロック A：サーボ。XH-3 を 8 個、左の縁に J1-4〜11 の向かいに縦一列で

各コネクターの接点：
**1：信号**（DevKit に近い側）・**2：サーボ用 +5V**・**3：GND**（縁側）。これはサーボの線の順序です。オレンジ、赤、茶の順になります。

| コネクター | 表示 | つなぐもの | GPIO（ピン） |
|---|---|---|---|
| A1 | AIL-L | 左エルロン | 4（J1-4） |
| A2 | AIL-R | 右エルロン | 5（J1-5） |
| A3 | ELE | エレベーター | 6（J1-6） |
| A4 | ESC | スピードコントローラー：スロットルの信号。**赤い線は BEC の 5V 入力** | 7（J1-7） |
| A5 | AUX1 | ペイロード投下用のサーボ | 15（J1-8） |
| A6 | AUX2 | フラップ（2 個のサーボを Y ケーブルで）または任意のサーボ | 16（J1-9） |
| A7 | RC | 受信機 FS-iA6B の iBUS SERVO ポート（受信機はここから給電される） | 17（J1-10） |
| A8 | RUD | ラダー + 車輪 | 18（J1-11） |

このブロックにはんだ付けするものは、ほかにもあります。

- **サーボ用 +5V のバス**：接点の中央の列で、配線は 2 mm 以上。**GND**：外側の列で、GND リングの一部でもあります。
- 各信号線の途中、コネクターの近くに **330 Ω（0603）** を直列に入れます。信号の接点に 5 V がかかっても（サーボの故障、圧着の不良など）、ESP のピンは無事です。
- A4 ESC の信号から GND へ **10 kΩ（0603）** を入れます。ESP が再起動している間、スピードコントローラーにノイズが入りません。
- 各コネクターの接点 2 と 3 の間に **100 nF（0805）** を入れます。
- **A4 ESC** には、さらに 10 µF + 100 pF（0805）を付けます。基板全体の電源入力で、低周波・高周波・超高周波のフィルターになります。
- **A7 RC** には、さらに 10 µF（0805）を付けます。受信機は電圧の落ち込みに敏感です。
- **2 × 470 µF 16 V** をサーボのバスに、列の両端に 1 個ずつ（A1 の上と A8 の下）入れます。プラスをバスに、マイナスをリングにつなぎます。列の途中ではマイナスをリングまで届かせられませんが、電解コンデンサーなら、幅広の配線で 3 cm 引き回しても影響はありません。

ESC 用のソケット 1 つで約 3 A まで流せます。MG90S サーボ 4〜6 個ならこれで足ります。サーボがそれより増えて、しかも大きなものになるなら、A4 の隣に BEC からの別の電源ソケットを追加してください。

### ブロック B：バッテリーとテレメトリー、左下でサーボの下

**B1 BAT：XH-5**（基板上で唯一の XH-5 です。12〜17 V のケーブルは、ほかのどのコネクターにも入りません）

| ピン | 内容 | 基板上の接続先 |
|---|---|---|
| 1 | **VBAT**：細い線でバッテリーのプラス（バランス端子の端の「+」、またはバッテリーのコネクターから。ESC 経由にはしない） | 56 kΩ / 10 kΩ の分圧器 → GPIO8（J1-12） |
| 2 | 空き：バッテリー電圧とほかの端子とを隔てるすき間 | — |
| 3 | **CURR**：電流センサーの出力 | 10 kΩ / 15 kΩ の分圧器 → GPIO3（J1-13） |
| 4 | ロジック用 +5V：電流センサーの電源 | ロジック用 5V のバス |
| 5 | GND | リング |

- **VBAT の分圧器**：上が 56 kΩ、下が 10 kΩ で、下側に 100 nF を並列に入れます。3S（12.6 V）→ 1.91 V、4S（16.8 V）→ 2.55 V となり、ADC の上限（約 3.1 V）まで余裕があります。グランドの専用線は不要です。グランドは ESC 経由で共通になっているので、ピン 5 は圧着しなくてもかまいません。
- **CURR の分圧器**：上が 10 kΩ、下が 15 kΩ で、下側に 100 nF を並列に入れます。5 V のホール式センサー（ACS758 など）の出力は最大 5 V で、ピンでは 3.0 V になります。センサーの出力が 3.3 V なら、上の抵抗は 0 Ω にして、下の抵抗ははんだ付けしません。
- 分圧器はコネクターのすぐそばに置き、グランドはそのピン 5 から取ります。こうすると ESP へ行く配線は 1 本で済みます。
- 電流センサーがまだない場合は、ピン 3〜4 を圧着しないでおきます。

**B2 TELEM：XH-4**。テレメトリーの無線モデム、または iBUS-SENS 用です。

| ピン | 内容 | GPIO（ピン） |
|---|---|---|
| 1 | TX → モデムの RX へ | 9（J1-15） |
| 2 | RX ← モデムの TX から | 10（J1-16） |
| 3 | ロジック用 +5V | — |
| 4 | GND | — |

- ピン 3 と 4 の間に 10 µF + 100 nF を入れます。1 W のモデムには、470 µF の電解コンデンサーを追加します。
- ファームウェアは TELEM にまだ対応していません。3 つの UART がすべて使用中（コンソール、iBUS、GPS）だからです。有効にするには、コンソールを内蔵 USB に移す必要があります。これはファームウェアの変更です。コネクターの配線は今のうちから済ませておけます。

### ブロック C：3V3 の画面とセンサー、右上

このエリアのものはすべて **I2C レール**に載ります（第 3 節の項目 5）。DevKit から外へ向かう 4 本の配線 **3V3 · GND · SCL · SDA** です。SCL は GPIO42（J3-6）、SDA は GPIO41（J3-7）から来ます。3V3 は J1-1/2 から上側を回って来ます。OLED はレールの一番下に置き、その上に順に C2〜C5 を並べます。

**C1 OLED：XH-4**。電源はレールから、データは専用のバス（GPIO1/2）から取り、内側から配線します。

| ピン | 内容 | 接続元 |
|---|---|---|
| 1 | SDA | GPIO1（J3-4） |
| 2 | SCL | GPIO2（J3-5） |
| 3 | 3V3 | レール |
| 4 | GND | レール |

これは OLED モジュールのピン順（GND VCC SCL SDA）を逆にしたものなので、ケーブルをねじらずに配線できます。

**C2 I2C-A と C3 I2C-B：XH-4**、どちらも同じです。

| ピン | 内容 |
|---|---|
| 1 | 3V3 |
| 2 | GND |
| 3 | SCL |
| 4 | SDA |

- **C2**：コンパス用。マストに載せた GY-273（ストレートのケーブルで、順序はモジュールと同じ）か、GPS モジュールのコンパスです。GPS では GND、SCL、SDA だけを圧着します。コンパスの電源は GPS のケーブルから得ます。
- **C3**：予備用。対気速度センサー（MS4525DO）や距離計などをつなぎます。

**C4 BARO：BMP581 モジュール用の 1×4 ソケット**。1：VCC、2：GND、3：SCL、4：SDA。

- モジュール側に、ワイヤーのジャンパー **CSB→VCC** と **SDO→GND** をはんだ付けします（アドレス 0x46。0x47 はピトー管用に空けておきます）。CSB→VCC がないと、チップは SPI モードになってしまいます。SDO を浮かせるとアドレスが定まりません。モジュールのそのほかのピンは空中に浮かせたままにします。
- 電源はレールの 3V3 だけにします。多くの BMP581 モジュールには専用のレギュレーターがありません。
- モジュールはメーカーによってピン順が違うので、お使いのものを確認してください。合わない場合は、モジュールをケーブルで C3 につなぎ、ソケットは実装しません。
- 上には、気泡が連続したスポンジを少し載せます（空気の流れと光を防ぐため）。

**C5 IMU：GY-521 用の 1×8 ソケット**

| ピン | モジュールの端子 | 接続先 |
|---|---|---|
| 1 | VCC | 3V3 レール |
| 2 | GND | GND レール |
| 3 | SCL | SCL レール |
| 4 | SDA | SDA レール |
| 5, 6 | XDA, XCL | どこにもつながない |
| 7 | AD0 | レールの外側の GND ベタ（アドレス 0x68） |
| 8 | INT | どこにもつながない |

IMU を基板上でどの向きに置くかは問題ではありません。取り付けは `o` のキャリブレーションで決まります（PILOT_GUIDE の「IMU の取り付け」）。

単体の MPU-6500 モジュール（10 ピン：VCC GND SCL SDA EDA ECL AD0 INT NCS FSYNC）はピン順が違うため、このソケットには挿さりません。ケーブルで C3 につなぎ（VCC、GND、SCL、SDA）、モジュール側にジャンパー **NCS→VCC**（そうしないとチップが SPI モードになります）、**AD0→GND**（アドレス 0x68）、**FSYNC→GND** をはんだ付けします。

このブロックのコンデンサー：レール上の C1 の位置（3V3 が始まるところ）に **10 µF + 100 nF**、C2〜C5 ではピン 1 と 2 の間に **100 nF** を入れます。I2C のプルアップはすでにモジュール上にあるので、基板には付けません。

### ブロック D：ロジック用 5V の GPS、ブザー、ライト、右下

ロジック用 5V のバスは下から（DevKit の下を通って下の縁に沿って）入り、右の縁をブロック内のすべてのコネクターの「+5V」の接点を通りながら上へ上がっていきます。

**D1 GPS：XH-4**。レールのすぐ下に置き、GPS のソケットとそのコンパス（C2）のソケットが近くなるようにします。

| ピン | 内容 | GPIO（ピン） |
|---|---|---|
| 1 | TX → GPS の RX へ | 40（J3-8） |
| 2 | RX ← GPS の TX から | 39（J3-9） |
| 3 | ロジック用 +5V | — |
| 4 | GND | — |

ピン 3 と 4 の間に 10 µF + 100 nF を入れます。

**D2 BUZ：XH-2**。5 V のアクティブブザーで、草むらに落ちた機体を探したり、バッテリーや ARM について警告したりするためのものです。

| ピン | 内容 |
|---|---|
| 1 | ブザーの「−」 → スイッチ Q1 |
| 2 | ロジック用 +5V → ブザーの「+」 |

**D3 AUX3：XH-3**。1：GPIO47（J3-17）の信号を 330 Ω 経由で、2：ロジック用 +5V、3：GND で、さらに 2 と 3 の間に 100 nF を入れます。ボタン、LED テープのデータ、カメラのトリガーなどに使えます。**ここにサーボをつながないでください**。ロジック用 5V なので、サーボの電流がダイオードを通り、ESP の電源を揺らしてしまいます。

**D4 LIGHT：XH-2**。約 0.5〜1 A までの負荷用のスイッチです。航行灯、ヘッドライト、投下用の電磁石などに使います。

| ピン | 内容 |
|---|---|
| 1 | 負荷の「−」 → スイッチ Q2 |
| 2 | ロジック用 +5V → 負荷の「+」 |

**スイッチ Q1 と Q2** は同じ SOT-23 のフットプリントです。BC817 と Si2302 では、足の役割が対応しています。

| SOT-23 の足 | BC817 | Si2302 | 接続先 |
|---|---|---|---|
| 1 | ベース | ゲート | ← 1 kΩ ← GPIO（Q1 は 38、Q2 は 21）。足 1 から GND へ 10 kΩ |
| 2 | エミッター | ソース | GND（エリアのグランド：J3-21/22） |
| 3 | コレクター | ドレイン | コネクターのピン 1（D2 / D4） |

- **Q1（ブザー）**：どちらでも使えます。
- **Q2（ライト）**：**Si2302** を使います。BC817 は数百 mA で発熱します。
- 10 kΩ は、ESP が起動している間スイッチをオフに保ちます。ブザーが鳴り出したり、ライトがちらついたりしません。
- 負荷がコイル（電磁石、電磁式ブザー）の場合は、SS14 または 1N4148 のダイオードをコネクターと並列に、カソードを +5V 側にして入れます。ピン 1 と 2 の間にその場所を空けておいてください。

## 5. 電源とすべてのコンデンサー

```
 ESC (BEC 5V/5A) ──► A4 ──► サーボ用 5V バス ──┬──► A1…A8 （サーボ、受信機）
                                               │    列の両端に 2×470 µF
                                               │
                                               └──► ダイオード 1N5822 ──► ロジック用 5V ──┬──► J1-21 (5V DevKit)
                                                                                          ├──► B1, B2 （電流センサー、モデム）
                                                                                          └──► D1…D4 （GPS、ブザー、AUX3、ライト）
 DevKit：内蔵の 3V3 レギュレーター ──► J1-1/2 ──► 上側を通る ──► レール C（OLED、センサー、I2C コネクター）
```

- **入力は 1 つだけです：A4 ESC**。電源専用のコネクターは不要です。
- **ショットキーダイオード 1N5822**（3 A、リード品。SMD の代替品は SS34）は購入が必要です。これには 3 つの役割があります。
  - USB と BEC がぶつかりません。バッテリーをつないだまま USB も挿しておけます。
  - サーボがバスの電圧を落としても、ロジック側の電解コンデンサーがサーボへ逆流して放電することがなく、ESP も再起動しません。
  - リード品のボディが、J1-22 のそばの隅で GND の配線をまたぐジャンパーの役目をします。

  アノードはサーボのバスの下端に、カソードは J1-21 につなぎます。1N5819（1 A）は使わないでください。ESP、モデム、GPS、ライトの電流がすべてこのダイオードを通ります。
- USB だけではサーボに給電されません。ダイオードが切り離します。これは意図した動作です。机の上で USB から GPS、モデム、ブザーが動くのは、DevKit の 5V ピンが USB から電力を出す場合だけです。クローン品の中にはそこに独自のダイオードが入っていて、その場合は動きません。これは正常です。
- 3.3 V は DevKit のレギュレーターだけから、エリア C だけに供給します。

**すべてのコンデンサーを 1 つの表にまとめました**（セラミックは 0805、電解コンデンサーは 16 V）。

| 場所 | 内容 | 目的 |
|---|---|---|
| サーボのバス、A1 の上と A8 の下 | 470 µF + 470 µF | サーボが一斉に動いたときの電圧の落ち込み対策 |
| A4 ESC、+ と GND の間 | 10 µF + 100 nF + 100 pF | 電源入力：低周波、高周波、超高周波 |
| A1〜A3、A5〜A8 | それぞれに 100 nF | サーボのモーターのノイズ対策（発生源で） |
| A7 RC | + 10 µF | 受信機用 |
| ロジック用 5V、J1-21 | 470 µF + 10 µF + 100 nF | BEC が落ち込んだときに ESP を支える |
| 3V3 レール、C1 | 10 µF + 100 nF | センサーの電源用 |
| C2〜C5 | それぞれに 100 nF | |
| B1：VBAT と CURR の ADC 入力 | それぞれに 100 nF、下側の抵抗と並列 | ADC のフィルター |
| B1：電流センサーの +5V | ピン 4 と 5 の間に 100 nF | |
| B2 TELEM | 10 µF + 100 nF（1 W のモデムなら + 470 µF） | 送信機の電流のスパイク対策 |
| D1 GPS | 10 µF + 100 nF | |
| D3 AUX3 | 100 nF | |

0805 の 10 µF のセラミックコンデンサーは、5 V をかけると容量が最大で半分まで減ります。この点は織り込み済みで、近くには電解コンデンサーもあります。

テストポイント：**5VS**（サーボのバス）、**5VL**（ロジック用 5V）、**3V3**、**GND**。ここにテスターを当てると測りやすくなります。

## 8. 触ってはいけない GPIO

0、45、46：起動モードがこれらで決まります。19/20：USB。26〜37：N16R8 モジュールのフラッシュと PSRAM。43/44：「COM」コネクター（コンソール）。48：RGB LED。この計画で空いているのは GPIO11〜14 だけです（テストベンチでは SPI）。

## 9. 初めて電源を入れる前に

1. DevKit もバッテリーもつながない状態で導通を確認します。サーボ用 +5V ↔ GND、ロジック用 5V ↔ GND、3V3 ↔ GND のどこにもショートがあってはいけません。
2. BEC をつなぎます（A4 経由）。DevKit はまだ挿しません。5VS は 5.0〜5.2 V、5VL はそれより 0.3〜0.5 V 低い値（ダイオードでの電圧降下）になるはずです。
3. DevKit を挿し、USB だけをつなぎます。5VS は 0 V になります。ダイオードが USB の電力をサーボへ通しません。
4. すべてをつなぎます。コンソールの `s` で、センサーが応答しているか、I2C のエラーが何件あるかが分かります。

## 10. 前回の計画からの変更点

- **ピンを 1 層に収まるように振り直しました**（`Config.h` には反映済みです）。
  - センサーの I2C：8/9 → **41/42**
  - GPS：15/16 → **39/40**
  - AUX1/AUX2：41/42 → **15/16**
  - VBAT：3 → **8**、電流センサー：10 → **3**
  - テレメトリー：39/40 → **9/10**
  - 新しい出力 **LIGHT** を GPIO21 に追加

  テストベンチでは、電線を 2 本付け替えてください。SDA 8 → 41、SCL 9 → 42 です。ほかのピンは予備で、テストベンチではつないでいません。
- **BEC は ESC 経由の 1 つだけ**：専用の PWR コネクターはなくしました。
- **基板上のセンサーは I2C に接続**（テストベンチと同じです）。SPI のソケットはなくし、GPIO11〜14 は空きにしました。ICM-42688 は I2C でも動作しますが、ファームウェア側で `SensorSelection.h` に I2C 版を用意する必要があります。
- **GPS-MAG はなくしました**：GPS のコンパスは C2 に挿します。
- **VBAT と電流センサーは統合**して、1 つの XH-5（B1）にしました。

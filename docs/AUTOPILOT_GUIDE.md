# Справочник по автопилоту OpenPlane

Что умеет автопилот, как включить каждую функцию и как повесить её на любой тумблер или крутилку пульта **одной строкой**.

> Сначала — честно. Все режимы проверены юнит-тестами и замкнутыми симуляциями полёта (`test/native/test_sim`: вся прошивка управляет моделью самолёта). Модель упрощённая, а коэффициенты в `Config.h` — стартовые: **каждый режим сначала пробуется на высоте 50+ м с пальцем на тумблере MANUAL**. В полёте пока был только ручной режим (первый прототип на ESP32-C3); стабилизация проверена на стенде — рули отвечают на наклоны в правильную сторону. Плата STM32H743 собирается и проходит те же тесты; на железе проверена только голая плата DevEBox (SD-карта, чёрный ящик) — датчики и серво на ней ещё не подключались.

## Как это устроено за минуту

```
стики ──┐
        ├─► PilotSwitches (config/Controls.h) ─► режим, функции, крутилки
тумблеры┘                                              │
                                                       ▼
датчики (IMU, барометр, компас, GPS, трубка Пито) ─► Autopilot ─► команда рулей и газа
                                                       │
                          FlightController: закрылки, груз, камера, пищалка, failsafe
                                                       ▼
                                          элероны · руль высоты · руль направления · ESC · AUX1 · AUX2
```

- **Режим** решает, кто рулит: пилот (MANUAL), пилот с помощником (STABILIZE, ALT_HOLD, ACRO), автопилот с поправками пилота (CRUISE, LOITER, RTH…).
- **Функции** включаются поверх любого режима: закрылки, тормоз, сброс груза, геозабор…
- **Крутилки** плавно меняют число: силу стабилизации, скорость круиза, радиус кругов…
- В режимах со стабилизацией **стик задаёт угол**, а не отклонение руля: отпустили стик — самолёт сам встал в горизонт.
- Отказ датчика никогда не «дёргает» самолёт: нет IMU — рули остаются у пилота; нет барометра — высоту держит пилот; нет GPS — нет навигации, а режимы, которым он нужен, ведут себя безопасно (см. [таблицу](#что-нужно-каждому-режиму)).

## Раскладка пульта по умолчанию

FS-i6 + FS-iA6B, iBUS, 10 каналов (`config/Channels.h`).

| Канал | Орган пульта | По умолчанию |
|---|---|---|
| CH1–CH4 | стики | крен, тангаж, газ, руль направления (переназначить нельзя) |
| CH5 | **SwA** | **ARM** (вниз = заармлен, только при газе внизу; переназначить нельзя) |
| CH6 | SwB | закрылки (`Feature::FLAPS`) |
| CH7 | **SwC** (3 положения) | вверх **MANUAL** · середина **STABILIZE** · вниз **AUTO_TAKEOFF** |
| CH8 | SwD | **RTH** — домой, пока включён |
| CH9 | VrA | сила стабилизации (`Knob::STAB_GAIN`) |
| CH10 | VrB | скорость круиза (`Knob::CRUISE_SPEED`) |

При включении платы в монитор порта печатается фактическая раскладка — то, что реально прошито:

```
SwC (CH7): MANUAL / STABILIZE / AUTO_TAKEOFF (вверх / середина / вниз)
SwB (CH6): FLAPS, пока включён
SwD (CH8): RTH, пока включён
VrA (CH9): крутилка STAB_GAIN
VrB (CH10): крутилка CRUISE_SPEED
```

> Каналы 7–10 на FS-i6 по умолчанию не выведены. Меню пульта: **Functions setup → Aux. channels**, назначить SwC, SwD, VrA, VrB.

## Назначить функцию одной строкой

Всё в одном файле — `include/config/Controls.h`:

```cpp
constexpr Binding BINDINGS[] = {
    Bind::modes  (Channels::SWC, MODE_MANUAL, MODE_STABILIZE, MODE_AUTO_TAKEOFF),
    Bind::feature(Channels::SWB, Feature::FLAPS),
    Bind::mode   (Channels::SWD, MODE_RTH),
    Bind::knob   (Channels::VRA, Knob::STAB_GAIN),
    Bind::knob   (Channels::VRB, Knob::CRUISE_SPEED),
};
```

| Вид строки | Что делает |
|---|---|
| `Bind::modes(канал, вверх, середина, вниз)` | трёхпозиционный тумблер выбирает режим |
| `Bind::modes(канал, вверх, вниз)` | двухпозиционный — два режима |
| `Bind::mode(канал, режим)` | режим **поверх** остальных, пока тумблер включён; выключили — вернулся режим с тумблера режимов |
| `Bind::feature(канал, функция)` | функция работает, пока тумблер включён |
| `Bind::knob(канал, крутилка)` | крутилка: центр = значение из `Config.h`, края = минимум и максимум |

«Включён» — канал выше 1750 мкс (на FS-i6 — тумблер вниз, к себе). До первого кадра приёмника все каналы считаются выключенными: при подаче питания ничего не выпустится и не сбросится.

### Готовые рецепты

```cpp
// Термикующий планер: SwD — парение, SwB — автотриммер, VrB — радиус кругов
Bind::modes  (Channels::SWC, MODE_MANUAL, MODE_STABILIZE, MODE_CRUISE),
Bind::mode   (Channels::SWD, MODE_SOARING),
Bind::feature(Channels::SWB, Feature::AUTO_TRIM),
Bind::knob   (Channels::VRA, Knob::STAB_GAIN),
Bind::knob   (Channels::VRB, Knob::LOITER_RADIUS),

// Ученик: только стабилизация, RESCUE на "тревожной кнопке", мягкие стики
Bind::modes  (Channels::SWC, MODE_STABILIZE, MODE_ALT_HOLD, MODE_CRUISE),
Bind::mode   (Channels::SWD, MODE_RESCUE),
Bind::feature(Channels::SWB, Feature::GEOFENCE),
Bind::knob   (Channels::VRA, Knob::RATES),
Bind::knob   (Channels::VRB, Knob::MAX_BANK),

// Съёмка и доставка: камера со стабилизацией, сброс груза, кружение над точкой
Bind::modes  (Channels::SWC, MODE_STABILIZE, MODE_CRUISE, MODE_LOITER),
Bind::feature(Channels::SWB, Feature::PAYLOAD_DROP),
Bind::feature(Channels::SWD, Feature::CAMERA_STAB),
Bind::knob   (Channels::VRA, Knob::CAMERA_TILT),
Bind::knob   (Channels::VRB, Knob::LOITER_RADIUS),

// Запуск с руки без шасси: SwD — LAUNCH, закрылки плавно крутилкой
Bind::modes  (Channels::SWC, MODE_MANUAL, MODE_STABILIZE, MODE_CRUISE),
Bind::mode   (Channels::SWD, MODE_LAUNCH),
Bind::feature(Channels::SWB, Feature::AIRBRAKE),
Bind::knob   (Channels::VRA, Knob::FLAPS),
Bind::knob   (Channels::VRB, Knob::CRUISE_SPEED),
```

### Ошибки ловит компилятор

Таблица проверяется при сборке (`static_assert`), до того как прошивка попадёт в самолёт:

- стики и SwA (ARM) привязать нельзя, номер канала — меньше `Channels::COUNT`;
- у канала — только одна привязка;
- тумблер выбора режимов (`Bind::modes`) — не больше одного.

Если несколько тумблеров `Bind::mode` включены одновременно, побеждает верхняя строка таблицы.

## Режимы

Режим сменяется, когда тумблер **переключили**. Режим, включённый с дашборда или наземной станции, действует, пока пилот снова не щёлкнет тумблером режима. На OLED — короткое имя (в скобках).

### MANUAL (MAN)
Рули = стики, как без полётника. Работают только функции (закрылки, тормоз, груз) и автотриммер. **Главный режим безопасности**: всегда держите его на тумблере под пальцем.

### STABILIZE (STAB) — «стик задаёт угол»
Стик крена — угол крена до `MAX_BANK_DEG` (45°, крутилка `MAX_BANK` 15…60°), стик тангажа — угол до `STAB_MAX_PITCH_DEG` (25°). Отпустили — самолёт сам в горизонте. Газ — у пилота. Интегратор ПИД копится только вблизи цели (±10°), поэтому после резкого манёвра самолёт не «переваливает» горизонт.
**Нужно:** IMU. Без IMU — как MANUAL.

### ALT_HOLD (ALT) — «держи высоту»
Как STABILIZE по крену, а руль высоты держит высоту по барометру. Двинули стик тангажа — управляете сами; отпустили — самолёт держит **новую** высоту. Газ — у пилота (добавьте газу, иначе на подъём не хватит скорости).
**Нужно:** IMU + барометр.

### ACRO — «стик задаёт скорость вращения»
Полный стик — 180°/с. Отпустили — самолёт **держит тот угол, в котором был** (хоть вверх ногами), гироскоп гасит порывы. Для фигур.
**Нужно:** IMU. Без IMU — рули = стики.

### CRUISE (CRZ) — «держи курс, высоту и скорость»
Самолёт летит по прямой на текущей высоте, газ — сам (крутилка `CRUISE_SPEED`: 30…55…85 % газа, а с трубкой Пито — **воздушная скорость** 10…14…22 м/с). Стик крена — повернуть (отпустили — держит новый курс), стик тангажа — сменить высоту. С трубкой Пито работает защита от сваливания. Курс — по GPS (при путевой скорости > 3 м/с, обратно на компас — ниже 2 м/с), иначе по компасу, иначе по гироскопу. В симуляции при боковом ветре 4 м/с путевой курс держится в пределах ±5°, высота — ±3 м.
**Нужно:** IMU + барометр; GPS или компас для курса без ухода.

### LOITER (LOIT) — «кружи здесь»
Круги по часовой над точкой, где режим включили, радиус 50 м (крутилка `LOITER_RADIUS` 25…150 м), на текущей высоте, газ сам. Наведение — векторное поле: издалека самолёт заходит на окружность по касательной, на ней держит упреждающий крен. Без GPS — просто круг постоянным креном на месте.
**Нужно:** IMU + барометр + GPS.

### RTH — «домой»
Курс на дом (точка ARM), высота `RTH_ALTITUDE_M` = 40 м (ниже — набирает по пути, выше — остаётся). Над домом — круги радиуса LOITER, пока пилот не заберёт управление. Нет GPS или дома — круги на месте. Тот же режим включают потеря связи и геозабор.
**Нужно:** IMU + барометр + GPS с домом.

### AUTO_TAKEOFF (TKOFF) — «взлёт по газу»
После ARM ничего не происходит, пока пилот не поднимет газ выше середины. Дальше программа: 1 с разгон газом до 100 % крылья ровно, 2 с отрыв с тангажом 15°, потом набор с тангажом 10°, пока пилот не переключит режим. Стики добавляются поверх программы — выровнять курс на разбеге можно.
**Нужно:** IMU.

### LAUNCH (LNCH) — «запуск с руки»
1. Заармили, газ выше середины — запуск **взведён**, мотор стоит.
2. Бросок: перегрузка вперёд > 1.5 g дольше 40 мс.
3. Через 0.3 с (рука ушла от винта) — газ 100 %, набор с тангажом 15°, крылья ровно — 6 с или до 30 м.
4. Дальше — как CRUISE на достигнутой высоте.

Любое движение стиком (> 150 мкс) до броска — отмена: самолёт в руках пилота.
**Нужно:** IMU (акселерометр). В симуляции: бросок на 9 м/с с высоты руки — самолёт ни разу не касается земли и за 15 с набирает больше 15 м.

### AUTO_LAND (LAND) — «посадка»
Мотор выключен, планирование по курсу с тангажом −4°; ниже 3 м по барометру — выравнивание (+4°). Стик крена — поправить курс захода. Включать на прямой, против ветра, на 20–40 м, с запасом полосы. В симуляции касание — с вертикальной скоростью меньше 1.5 м/с, крылья ровно, не на нос.
**Нужно:** IMU + барометр (обнулён на земле при включении).

### SOARING (SOAR) — «парение в термиках»
Мотор выключен, планирование. Вариометр (с трубкой Пито — полной энергии, без ложных «термиков» от ручки на себя) выше 0.5 м/с дольше 1.5 с — термик: круги с креном 25°. Средний набор за 8 с упал ниже −0.2 м/с — выход из термика. Ниже 30 м — мотор до 100 м; дальше 400 м от дома — планирует домой. В симуляции находит термик (ядро 3 м/с) и набирает больше 50 м без мотора.
**Нужно:** IMU + барометр; GPS — для возврата к дому.

### RESCUE (RESQ) — «спасите»
Крылья ровно, нос +8°, газ 70 % — из любой спирали. Потерял ориентацию — щёлкнул и выдохнул. В симуляции из спирали с креном 70° и носом −40° за 4 с — крылья ровно и набор высоты.
**Нужно:** IMU.

## Функции (тумблеры)

| Функция | Что делает | Детали и числа (`Config.h`) |
|---|---|---|
| `FLAPS` | оба элерона вниз — флапероны | `FLAPS_DEPLOYED_US` = 220 мкс, плавно за 1 с; крен работает поверх |
| `AIRBRAKE` | оба элерона вверх — воздушный тормоз, круче глиссада | `AIRBRAKE_US` = 250; важнее закрылков |
| `AUTO_TRIM` | учится держать самолёт прямо без стиков: постоянная команда рулей в ровном полёте «перетекает» в триммер | 20 %/с, до ±120 мкс; сохраняется во флеш после DISARM **на земле** |
| `TURN_COORDINATION` | руль направления в разворот, нос вверх в крене | в навигационных режимах включена всегда |
| `MOTOR_KILL` | мотор выключен в любом режиме, даже в автоматических | сильнее любого режима и газа |
| `BEEPER` | пищалка «я здесь» | без тумблера пищит сама: на земле, связь потеряна > 10 с |
| `PAYLOAD_DROP` | серво AUX1 открыто, пока тумблер включён | 1000 мкс закрыто, 2000 открыто |
| `GEOFENCE` | дальше 500 м от дома или выше 120 м — RTH | `GEOFENCE_ALWAYS_ON` — без тумблера |
| `HOME_RESET` | дом = текущая точка (в момент включения тумблера) | только при хорошем GPS |
| `CAMERA_STAB` | камера на AUX2 держит угол к горизонту | вычитается тангаж самолёта |

## Крутилки

Центр крутилки = значение по умолчанию из `Config.h`; края — минимум и максимум. Не привязана — действует значение по умолчанию.

| Крутилка | Минимум … центр … максимум | Где действует |
|---|---|---|
| `STAB_GAIN` | ×0.25 … ×1 … ×2 | все режимы со стабилизацией и ACRO — «мягче/жёстче» |
| `MAX_BANK` | 15° … 45° … 60° | предельный крен со стика и навигации |
| `CRUISE_SPEED` | газ 30 … 55 … 85 % (с Пито: 10 … 14 … 22 м/с) | CRUISE, LOITER, RTH, мотор в SOARING |
| `FLAPS` | 0 … 50 … 100 % закрылков | плавные закрылки вместо тумблера |
| `CAMERA_TILT` | −90° … 0° … +30° | угол камеры (AUX2) |
| `RATES` | 30 … 65 … 100 % хода стиков | все режимы: чувствительность стиков |
| `LOITER_RADIUS` | 25 … 50 … 150 м | LOITER и круги над домом |

> Полезный приём: крутилка `STAB_GAIN` на VrA — это «живой» подбор коэффициентов в полёте. Раскачивает — убавьте; вялый — прибавьте; потом перенесите множитель в `Config.h`.

## Потеря связи, геозабор, дом

**Дом** записывается при ARM, если GPS хороший (3D-фикс, ≥ 6 спутников, точность ≤ 5 м). Если к ARM GPS ещё не поймал — дом запишется, как только поймает. Сменить в поле — функция `HOME_RESET`.

**Потеря связи** (кадров iBUS нет > 0.5 с или приёмник прислал газ ниже 950 мкс — это failsafe, настроенный в пульте; см. `docs/PILOT_GUIDE.md`):

| Ситуация | Что делает борт |
|---|---|
| на земле (не заармлен) | мотор 0, рули в нейтраль; через 10 с — пищалка |
| в воздухе, GPS и дом есть | **RTH** с мотором, над домом — круги на 40 м |
| в воздухе, GPS нет | **планирование**: мотор выключен, крылья ровно, нос −3° |
| связь вернулась | сразу режим с тумблера пилота |

Уже начатый возврат не бросается в планирование от короткой потери GPS. `FAILSAFE_RTH = false` — только планирование.

**Геозабор** (`GEOFENCE` или `GEOFENCE_ALWAYS_ON`): вылет дальше `FENCE_RADIUS_M` (500 м) или выше `FENCE_ALTITUDE_M` (120 м) — RTH. Забрать управление — щёлкнуть тумблером режима в любое другое положение (режим включается сменой положения). Снова сработает, когда самолёт вернётся внутрь с запасом 10 %.

## Трубка Пито своими руками

Воздушная скорость без покупного датчика дифференциального давления: **два барометра**.

```
       набегающий поток ─►  ┌──────────── трубка (ПВХ/латунь Ø4–6 мм) ──┐
                            │  BMP581 (I2C 0x47) — полное давление      │  герметично
                            └────────────────────────────────────────────┘
   фюзеляж: основной барометр (BMP581 0x46 / SPL06 / BMP388) — статическое давление

   скорость  V = √(2·(P_трубки − P_статики − ноль) / ρ),   ρ — из статики и температуры
```

**Сборка.** BMP581 (модуль с адресом 0x47: ножка SDO на VCC) заклеивается в трубку, открытую только вперёд, — плата внутри герметичной полости, провода выведены через герметик. Трубка — вперёд, вне потока от винта (на крыле или над носом). Второй барометр — внутри фюзеляжа, закрыт от прямого потока (поролон).

**Включение в прошивке** — `sensors/SensorSelection.h`: `SENSOR_KIT_LSM6DSV_PITOT` или `SENSOR_KIT_ICM45686_PITOT` (готовые наборы), или `SENSOR_AIRSPEED = SENSOR_AIRSPEED_PITOT_BMP581` в своём наборе.

**Ноль.** Два барометра всегда немного расходятся: абсолютная точность каждого — десятки паскалей, а это и есть весь перепад на малой скорости (10 м/с ≈ 60 Па). Первую секунду после включения прошивка усредняет разность и считает её нулём. **Самолёт при включении стоит, трубка закрыта пальцем/колпачком или развёрнута по ветру.** На OLED, в дашборде и телеметрии скорость появится после обнуления.

**Калибровка `PITOT_SCALE`.** Давление в фюзеляже не строго статическое. В безветрие пролетите прямую туда и обратно в CRUISE, сравните среднюю путевую скорость GPS со скоростью трубки: `PITOT_SCALE = V_GPS / V_трубки`.

**Защита.** Перепад сильно отрицательный дольше 2 с (шланги перепутаны, вода) или отсчёты трубки старше 0.2 с — скорость не выдаётся, автопилот переходит на газ по крутилке и курс без неё. Проверено в замкнутой симуляции с шумом обоих барометров: ошибка скорости в полёте < 0.5 м/с.

Что даёт трубка: CRUISE держит **воздушную скорость**, а не газ; защита от сваливания; вариометр полной энергии для SOARING; честная скорость в телеметрии.

## Наземная станция: Wi-Fi дашборд и MAVLink

**ESP32 — Wi-Fi дашборд.** Точка доступа `OpenPlane-Debug`, пароль `12345678`, адрес в мониторе порта. Каналы, выходы, все датчики, режим, навигация, включённые функции; можно сменить режим и ПИД. Подробно — `docs/PILOT_GUIDE.md`.

**STM32H743 — MAVLink по радиомодему** (UART4: PD0 RX, PD1 TX, 57600 бод — дефолт SiK). Подходит SiK 433/868/915 МГц, ELRS в режиме MAVLink, ESP-01 как Wi-Fi-мост. **QGroundControl** и **Mission Planner** видят борт как самолёт ArduPilot:

- горизонт, карта с домом, скорость (по трубке, если есть), высота, вариометр, газ;
- режимы — именами ArduPlane: STABILIZE → FBWA, ALT_HOLD → FBWB, CRUISE → CRUISE, LOITER → LOITER, RTH → RTL, AUTO_TAKEOFF/LAUNCH → TAKEOFF, SOARING → THERMAL, RESCUE → STABILIZE, AUTO_LAND → AUTO; failsafe показывается как RTL или CIRCLE;
- лента сообщений: ARM/DISARM, смена режима (нашим именем), потеря связи, геозабор;
- **смена режима с земли** — кнопкой режима в GCS (кроме AUTO: миссий у OpenPlane нет);
- **параметры** `RLL_KP … PTCH_KD` — ПИД крена и тангажа, читаются и меняются из окна параметров GCS прямо в полёте (не сохраняются после перезагрузки — удачные значения перенесите в `Config.h`).

ARM/DISARM с земли **отклоняется** — только тумблером пульта. Проверить поток без железа: `OPENPLANE_MAVLINK_DUMP=/tmp/tlm.bin pio test -e native -f native/test_mavlink && python3 tools/check_mavlink.py /tmp/tlm.bin` (нужен `pip install pymavlink`).

## Порядок настройки нового самолёта

1. **MANUAL на земле:** направления рулей (`*_REVERSED` в `Config.h`), закрылки вниз, AUX. Проверка выходов — `p` в консоли (пропеллер снять!).
2. **Датчики на земле:** `b` — опрос шин, `s` — статус; `o` — калибровка установки IMU (3 позы, один раз), `m` — компас.
3. **STABILIZE на земле:** наклоните самолёт вправо — правый элерон должен пойти **вниз** (выровнять). Нос вверх — руль высоты вниз. Не так — перепутаны реверсы или установка IMU.
4. **Первый полёт в MANUAL**, набор 50+ м → STABILIZE. Раскачивает — `STAB_GAIN` меньше; вялый — больше.
5. **AUTO_TRIM** в ровном полёте 20–30 с, посадка, DISARM — триммер сохранится.
6. **ALT_HOLD**, потом **CRUISE** — проверить высоту и курс; с трубкой — откалибровать `PITOT_SCALE`.
7. **LOITER** и **RTH** — на высоте, в пределах видимости, палец на MANUAL.
8. Только после этого — **failsafe-тест** (выключить пульт на высоте, самолёт должен пойти домой) и автоматические взлёт/посадка.

## Предполётная проверка автопилота

- [ ] Раскладка, напечатанная при включении, — та, что вы ждёте.
- [ ] Консоль/OLED: IMU ok, предполётная проверка IMU пройдена (самолёт стоял неподвижно при включении).
- [ ] Барометр обнулён на земле (высота ~0 на OLED).
- [ ] С трубкой: скорость ~0 на земле, дуете в трубку — растёт.
- [ ] GPS: 3D-фикс, ≥ 6 спутников **до ARM** — иначе не будет дома и RTH.
- [ ] STABILIZE на земле: элероны и руль высоты выравнивают самолёт, а не заваливают.
- [ ] Failsafe в пульте настроен (газ ниже 950 при потере связи) и проверен выключением пульта **на земле** без пропеллера.
- [ ] MANUAL — под пальцем.
